### A. system タイル ─ TOP プロセスカテゴリ追加　✅ 仕様明確

**概要**  
システムタイルに新カテゴリ「TOPプロセス」を追加する。CPU使用率上位3プロセスを表示する。

**仕様**

| 項目 | 内容 |
|---|---|
| カテゴリ名 | `top_process` |
| デバイス種別 | なし |
| 対象 | なし（固定） |
| 表示形式 | テキスト表示のみ |
| 取得方法 | CPU 使用率降順で上位3件 |

**表示レイアウト**

```
プロセス名    │ CPU  │ GPU  │ RAM
プロセスA     │  3%  │  0%  │  4MB
プロセスB     │  2%  │  0%  │  2MB
プロセスC     │  1%  │  0%  │  1MB
```

- `│` は明確なラインで仕切る（等幅フォント前提）
- 列幅は固定しレイアウトを揃える
- プロセス名が長すぎる場合、`│` 手前で省略（末尾 `…`）

**更新対象定義書**
- `function/アプリケーション機能定義.md` §3.5 システム情報セクション（カテゴリ追加）
- `data/設定ファイルフォーマット.md` §3.3（`systemInfo.category` に `"top_process"` 追加）

### C. カラー選択方式の改善　✅ 仕様確定

**概要**  
カラー選択プルダウンの末尾に「カスタム」項目を追加する。既存の 11 色定義は維持する。

**仕様**

| 項目 | 内容 |
|---|---|
| 既存 11 色 | そのまま維持 |
| 追加項目 | プルダウンの最後に「カスタム」を追加 |
| カスタム選択時 | カラーピッカー画面を起動し、任意の色を作成・保存できる |
| 保存後 | 作成した色がそのカラー設定に反映される |

**確定仕様（追加）**

| # | 項目 | 内容 |
|---|---|---|
| C-1 | 保存先 | `config.json` にトップレベルキー `customColor` を追加（単一オブジェクト） |
| C-2 | 名前 | なし。プルダウン表示は「カスタム」固定 |
| C-3 | 保存件数 | 1件のみ。カラーピッカーで別の色を保存すると上書きされる |

**`config.json` フォーマット（追加分）**

```json
{
  "global":  { ... },
  "layout":  { ... },
  "pages":   [ ... ],
  "customColor": "#3A7BD5"
}
```

- 未設定時は `null`（カスタム項目はプルダウンに表示されるが値なし扱い）

**更新対象定義書**
- `function/アプリケーション機能定義.md` §3.6（カラーパレットにカスタム色の扱いを追記）
- `ui/ランチャー本体.md` §8（カラー選択方式）
- `data/設定ファイルフォーマット.md`（カスタム色の保存形式）

### D. フォントサイズのスライダー操作＋自動調整　✅ 仕様明確

**仕様**

| 項目 | 内容 |

**config への保存**

| キー | 型 | 説明 |
|---|---|---|
| `autoFontSize` | boolean | `true` で自動調整 ON |

**更新対象定義書**

### E. 自動実行管理ツール　✅ 仕様確定

**概要**  
Windows タスクスケジューラー（現在ユーザーのみ・管理者権限不要）を利用して、定期自動実行するタスクをアプリ内から追加・削除・管理する機能。

**確定済み仕様**

| 項目 | 内容 |
|---|---|
| 権限 | 現在のユーザーのみ（管理者権限不要のタスク） |
| アクセス方法 | 設定モードのタイル一覧に「自動実行管理」タイルを追加（全体設定タイルの隣） |
| 画面遷移 | タイルをクリック → 自動実行管理画面へ移行 |
| 管理範囲 | アプリが作成したタスクのみ（OS 全体のタスクは表示しない） |
| タスク格納先 | タスクスケジューラーに専用フォルダを作成（フォルダ名：`\AppLauncher\`） |
| 画面位置 | フレーム内（他の設定画面と同じ構成） |

**E-1: 管理対象ファイル種別**

| 種別 | 拡張子 |
|---|---|
| 実行ファイル | `.exe` |
| スクリプト | `.bat` / `.ps1` / `.py` |

**E-2: スケジュール設定**

| 種別 | 内容 |
|---|---|
| 指定時間 | 毎日 / 毎週 / ログオン時 / PC起動時 から選択。毎日・毎週は時刻（HH:MM）を指定。毎週は曜日も選択 |
| 指定間隔 | 実行間隔を 1 分単位で指定 |

**E-3: 管理画面 UI 要素**

| 要素 | 内容 |
|---|---|
| タスク一覧 | タスク名・ファイル種別・スケジュール・前回実行時刻・実行結果を表示 |
| 有効・無効切替ボタン | 各タスク行に配置 |
| 追加・編集・削除ボタン | 各タスク行、または一覧上部に配置 |
| モックアップ | `docs/mockup/06_auto_exec.html` 参照（実装前に確認） |

**E-4: 実行結果表示**

- 最終実行時刻（日時）を表示する
- 実行結果（成功 / 失敗 ＋ 終了コード）を表示する

**E-5: 画面位置**

フレーム内（他の設定画面と同じ構成）

**ログ機能仕様（確定）**

| 項目 | 内容 |
|---|---|
| 保存先 | アプリ保存フォルダ内 `logs/autoexec/` |
| ファイル形式 | `.log` ファイル（タスクごと、またはまとめて 1 ファイル） |
| アプリからの参照 | 不可（ファイルとして保存するのみ） |
| 保存件数 | 過去 N 件のみ保持。N を超えたら古いものから削除 |
| ログ取得タイミング | アプリ起動時・終了時に OS 側のタスクスケジューラーログを読んで登録 |

**確定仕様（E-6〜E-7）**

| # | 確認項目 | 確定内容 |
|---|---|---|
| E-6 | ログ保持件数 | **50件固定**。設定画面・config への保存は不要 |
| E-7 | アンインストール時のタスク削除 | 管理画面フッターに「**全タスクを削除**」ボタンを設ける。ユーザーはこのボタンでタスクを削除してから exe を削除する。削除前に確認ダイアログを表示する |

**更新対象定義書**（E-6・E-7 確定後）
- `function/アプリケーション機能定義.md`（新セクション追加）
- `ui/ランチャー本体.md`（設定モードタイル一覧に追加、自動実行管理画面 UI 仕様）
- `data/設定ファイルフォーマット.md`（ログ保持件数の保存形式）

### H. タイル上のダブルクリックでピンモードが切り替わらないようにする　✅ 仕様明確

**概要**  
現在、通常モードでランチャーフレーム上をダブルクリックするとピンモードの ON/OFF が切り替わる。  
タイル上でのダブルクリックはこの操作対象から除外し、ピンモードが切り替わらないようにする。

**仕様**

| 項目 | 内容 |
|---|---|
| 現状 | タイル上でダブルクリックするとピンモードが切り替わる |
| 修正後 | タイル上でのダブルクリックはピンモード切替の対象外とする |
| 対象コード | `LauncherWindow.xaml.cs` `IsInteractiveTarget()` または `OnMouseDoubleClick()` |

**更新対象定義書**
- `function/アプリケーション機能定義.md` §2.2（ピンモードONの遷移条件にタイル除外を明記）

### G. カラースタイル管理機能　✅ 仕様確定

**概要**  
タイル編集画面にカラースタイルのプリセット管理機能を追加する。スタイルはカラー設定のみが対象。

**確定済み仕様（タイル）**

**UI 構成（タイル編集パネル 基本セクション最上部）**

```
[ カラースタイル: ▼ デフォルト1         ]   ← 選択プルダウン
  ↓ 現在のカラー設定がスタイルから逸脱した場合
[ カラースタイル: ▼ カスタマイズ        ]
┌─ カラースタイル設定 ─────────────────┐
│  [ 保存 ]  [ 削除 ]                  │
└──────────────────────────────────────┘
```

| 操作 | 動作 |
|---|---|
| スタイル選択 | プルダウンでスタイルを選び、そのカラー設定を適用する |
| カスタマイズ表記 | 選択中スタイルと現在のカラー設定が異なる場合、プルダウンに「カスタマイズ」と表示 |
| 「保存」ボタン | カスタマイズ中のみ表示。クリックすると設定名入力ダイアログが開く |
| 設定名入力ダイアログ | テキスト入力 ＋ OK ＋ キャンセル。OK 押下でスタイルを保存・プルダウンに追加 |
| 「削除」ボタン | カスタマイズ中のみ表示。ユーザー作成スタイルのみ削除可能 |
| 削除確認ダイアログ | タイル削除と同じ形式の確認ダイアログ |
| デフォルトスタイル | 削除不可 |

**確定仕様（G-1〜G-4）**

| # | 項目 | 内容 |
|---|---|---|
| G-1 | スタイルの対象設定 | 色＋透過率のみ。1スタイルにつきタイル色は1色（メイン色のみ。サブ・アクセントなし） |
| G-2 | デフォルトスタイル | 5件。下表参照 |
| G-3 | 適用範囲 | タイル＋ページ両方にそれぞれスタイル管理を追加 |
| G-4 | 保存先 | `config.json` に追記（`tileStyles`・`pageStyles` セクション） |
