## 3. アーキテクチャパターン

**MVVM（Model-View-ViewModel）** を採用します。

```
Model  ← config.json のデータ構造をそのまま表現
  ↓ (読み込み/変換)
ViewModel  ← UI 状態・コマンドを管理
  ↓ (バインディング)
View (XAML)  ← 表示のみ担当
```

### 責務の分担

| 層 | 内容 |
|---|---|
| **Models** | `GlobalConfig` / `PageConfig` / `TileConfig` など設定データクラス。カラーパレット定義 |
| **ViewModels** | ランチャーの状態（現在モード・現在ページ等）、コマンド（タイルクリック・ページ切り替え等） |
| **Views** | XAML の UI 定義。コードビハインドはUIイベントのみ（ロジックは持たない） |
| **Services** | 設定ファイル読み書き・タイル起動・スクリーン吸着・システム情報取得等のビジネスロジック |
| **Helpers** | カラー変換・ウィンドウサイズ算出等のユーティリティ |

## 5. ビルド構成

| 構成 | 説明 |
|---|---|
| **Debug** | 初期タイルあり（`../function/アプリケーション機能定義.md` § 3.8 参照）。コンソールウィンドウ非表示 |
| **Release** | 初期タイルなし（空ページ 4 枚）。`PublishSingleFile` で単一 exe 出力 |

**プロジェクトファイル設定概要（`.csproj`）**

```xml
<PropertyGroup>
  <TargetFramework>net10.0-windows</TargetFramework>
  <UseWPF>true</UseWPF>
  <ApplicationIcon>Resources\Icons\app.ico</ApplicationIcon>
  <Nullable>enable</Nullable>
  <ImplicitUsings>enable</ImplicitUsings>
</PropertyGroup>
```
