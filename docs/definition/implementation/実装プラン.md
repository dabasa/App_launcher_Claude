# 実装プラン

このドキュメントは、アプリランチャーの段階的な実装計画を定義します。  
各フェーズは前のフェーズの完了を前提とし、フェーズ単位で動作確認できることを目標とします。

---

## フェーズ一覧

| フェーズ | 名称 | 主な成果物 |
|---|---|---|
| **Ph.1** | プロジェクト基盤 | config.json 読み書き・カラーパレット |
| **Ph.2** | フレームレスウィンドウ | ウィンドウ表示・ハンドル・画面吸着 |
| **Ph.3** | タイルグリッド表示 | タイル・ページ・ボトムバーの静的表示 |
| **Ph.4** | タイル起動・ホバー | app/url/folder クリック起動・ホバーアニメーション |
| **Ph.5** | 収納モード・ピンモード | 自動収納アニメーション・ピン固定 |
| **Ph.6** | 編集モード基盤 | モード切替・ページ管理 |
| **Ph.7** | タイル編集 | タイルの配置・移動・リサイズ・削除 |
| **Ph.8** | 設定画面 | タイル編集・ページ編集・全体設定の UI |
| **Ph.9** | 高度なタイル機能 | D&D・system タイル・GIF・webview |
| **Ph.10** | タスクトレイ・仕上げ | トレイアイコン・マルチモニター・最終調整 |

---

## Ph.1 プロジェクト基盤

### タスク

- [ ] WPF ソリューション・プロジェクト作成（`AppLauncher.sln` / `AppLauncher.csproj`）
- [ ] NuGet パッケージ追加（`CommunityToolkit.Mvvm`, `System.Text.Json`, `Hardcodet.NotifyIcon.Wpf`）
- [ ] フォルダ構成作成（Models / ViewModels / Views / Services / Helpers / Resources）
- [ ] `Models/Config/` 各クラス実装（`AppConfig`, `GlobalConfig`, `LayoutConfig`, `PageConfig`, `TileConfig`, `SystemInfoConfig`）
- [ ] `ColorPalette.cs` 実装（カラー名 → `Color` 変換、11 色定義）
- [ ] `ConfigService.cs` 実装（config.json の読み書き・初期値生成）
- [ ] `WindowSizeCalculator.cs` 実装（ウィンドウサイズ算出式）
- [ ] Debug / Release ビルド構成設定
- [ ] Debug 用初期タイルデータ定義（`アプリケーション機能定義.md § 3.8` 参照）

### 完了条件

- アプリ起動時に `config/config.json` が存在しない場合、初期値で自動生成される
- 既存の config.json が正しく読み込まれる
- カラー名から `Color` オブジェクトに変換できる
- ウィンドウサイズ算出式が正しい値を返す（縦 4 × 横 6 の場合：幅 656 px、高さ 494 px）

## Ph.2 フレームレスウィンドウ

### タスク

- [ ] フレームレス・透過対応 WPF ウィンドウ作成（`LauncherWindow.xaml`）
- [ ] 角丸背景の実装（`frameCornerRadius = 20 px`）
- [ ] ページ背景色・透過率のバインディング

- [ ] `SnapService.cs` 実装
  - [ ] 右端吸着（画面右端から `screenEdgeDistance` を保持）
  - [ ] `alwaysOnTop` 設定
  - [ ] 吸着面に平行なドラッグ移動（縦スライド）
  - [ ] ドラッグ速度を自然な追従速度に
- [ ] ウィンドウサイズを `WindowSizeCalculator` 算出値で設定

### 完了条件

- アプリが画面右端に吸着した状態で起動する
- ハンドルがフレーム左側の上下中央に表示される
- 画面端から 20 px の距離を保ちながら上下にドラッグで移動できる
- 他のウィンドウの最前面に常に表示される

## Ph.5 収納モード・ピンモード

### タスク

- [ ] 収納待ち時間タイマー実装（マウスオーバー離脱 → `storageDelayMs` 後に収納）
- [ ] 収納アニメーション実装（1 秒でフレームが画面端外へスライド、ハンドルのみ残留）
- [ ] 収納解除アニメーション実装（ハンドルにマウスオーバー → 1 秒で展開）
- [ ] ピンモード実装
  - [ ] 空エリアダブルクリックで ON/OFF 切り替え
  - [ ] ピンモード ON 時に収納しない
  - [ ] ピンモード枠の表示（フレーム外周・色・透過率）
- [ ] 収納中に右クリックしてもメニュー非表示
- [ ] タスクバー下端吸着時：タスクバー上端を画面端として扱う

### 完了条件

- マウスが離れると `storageDelayMs` 後にフレームが画面端へ収納される
- ハンドルにマウスオーバーで展開される
- 収納・展開アニメーションが 1 秒で完了する
- ピンモード ON 中は収納されない
- ピンモード ON 時にフレーム外周に枠が表示される

## Ph.6 編集モード基盤

### タスク

- [ ] 編集モード切り替え実装（モード切替ボタン → オレンジ色）
- [ ] 編集モード自動ピン（編集モード中はピンモード強制 ON）
- [ ] ボトムバー編集モード実装
  - [ ] 行 1：ページインジケーター（中央） ＋ 設定遷移ボタン群（右寄せ）
  - [ ] 行 2：ページ管理コントロール（← ⊕ ⊖ → 中央揃え）
  - [ ] フレーム下方向拡張（33 px）
- [ ] ページ管理コントロール実装
  - [ ] `⊕`：ページ追加（配色継承・上限 10）
  - [ ] `⊖`：ページ削除（タイル未配置時のみ・最小 1）
  - [ ] `←` / `→`：ページ順序入れ替え（端でループなし）

### 完了条件

- 通常モード ↔ 編集モードがボタンで切り替えられる
- 編集モード時ボトムバーが 2 行になりフレームが 33 px 拡張される
- ページの追加・削除・順序変更ができる
- ページ上限（10）・下限（1）で対応ボタンが非活性になる
