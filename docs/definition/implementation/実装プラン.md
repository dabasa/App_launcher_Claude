# 実装プラン

このドキュメントは、アプリランチャーの段階的な実装計画を定義します。  
各フェーズは前のフェーズの完了を前提とし、フェーズ単位で動作確認できることを目標とします。

---

## フェーズ一覧

| フェーズ | 名称 | 主な成果物 |
|---|---|---|
| **Ph.1** | プロジェクト基盤 | config.json 読み書き・カラーパレット |
| **Ph.2** | フレームレスウィンドウ | ウィンドウ表示・ハンドル・画面吸着 |
| **Ph.3** | タイルグリッド表示 | タイル・ページ・ボトムバーの静的表示 |
| **Ph.4** | タイル起動・ホバー | app/url/folder クリック起動・ホバーアニメーション |
| **Ph.5** | 収納モード・ピンモード | 自動収納アニメーション・ピン固定 |
| **Ph.6** | 編集モード基盤 | モード切替・ページ管理 |
| **Ph.7** | タイル編集 | タイルの配置・移動・リサイズ・削除 |
| **Ph.8** | 設定画面 | タイル編集・ページ編集・全体設定の UI |
| **Ph.9** | 高度なタイル機能 | D&D・system タイル・GIF・webview |
| **Ph.10** | タスクトレイ・設定モード・仕上げ | 設定モード・トレイアイコン・マルチモニター・最終調整 |
