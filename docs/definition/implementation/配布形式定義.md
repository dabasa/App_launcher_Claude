## 1. 動作要件

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / Windows 11 |
| アーキテクチャ | x64 |
| .NET ランタイム | 不要（自己完結型ビルドに内包） |
| WebView2 ランタイム | 不要（`Microsoft.Web.WebView2` を内包） |
| インストーラー | 不要（ポータブル形式） |

## 2. 配布物の構成

### 2.1 exeに内包されるリソース

以下のリソースはビルド時に exe に埋め込まれるため、配布物に含める必要はありません。

| ファイル | 埋め込み方式 | 用途 |
|---|---|---|
| `resources/icons/app.ico` | `<Resource>` | アプリアイコン（exe・タスクトレイ） |
| `resources/image/mode01chg.png` | `<Resource>` | モード切替ボタン（通常モード） |
| `resources/image/mode02chg.png` | `<Resource>` | モード切替ボタン（編集モード） |
| `resources/image/mode03chg.png` | `<Resource>` | モード切替ボタン（設定モード） |

### 2.2 配布に含めるファイル

| ファイル | 説明 |
|---|---|
| `AppLauncher.exe` | ビルド成果物。.NET ランタイムおよび全リソースを内包した単一実行ファイル |

**配布物は `AppLauncher.exe` 単体のみです。**

## 3. 配布パッケージ形式

### 3.1 パッケージ形式

ZIP アーカイブ形式で配布します。インストーラーは使用しません（ポータブル形式）。

```
AppLauncher_v{バージョン}.zip
└── AppLauncher.exe
```

### 3.2 命名規則

| 項目 | 形式 | 例 |
|---|---|---|
| バージョン | セマンティックバージョニング（`major.minor.patch`） | `1.0.0` |
| ZIPファイル名 | `AppLauncher_v{バージョン}.zip` | `AppLauncher_v1.0.0.zip` |
| exe ファイル名 | `AppLauncher.exe`（固定） | — |

## 4. ビルド手順

### 4.1 ビルドコマンド

```powershell
cd src
dotnet publish AppLauncher/AppLauncher.csproj -c Release
```

### 4.2 出力先

```
src/AppLauncher/bin/Release/net10.0-windows/win-x64/publish/AppLauncher.exe
```

### 4.3 ビルド設定（Release 構成）

`.csproj` の Release 構成で以下が適用されます。

| 設定キー | 値 | 説明 |
|---|---|---|
| `RuntimeIdentifier` | `win-x64` | Windows x64 向けターゲット |
| `SelfContained` | `true` | .NET ランタイムを内包 |
| `PublishSingleFile` | `true` | 単一 exe に圧縮・結合 |
| `IncludeNativeLibrariesForSelfExtract` | `true` | ネイティブライブラリも内包 |
| `EnableCompressionInSingleFile` | `true` | exe のサイズを圧縮 |

### 4.4 バージョン管理

バージョン番号は `.csproj` の以下 3 項目を同期して更新します。

```xml
<Version>1.0.0</Version>
<AssemblyVersion>1.0.0.0</AssemblyVersion>
<FileVersion>1.0.0.0</FileVersion>
```

### 4.5 リリース前チェックリスト

- [ ] `Version` / `AssemblyVersion` / `FileVersion` が正しいバージョン番号に更新されている
- [ ] `DefineConstants` に `DEBUG_TILES` が含まれていない（Release 構成では自動除外）
- [ ] デバッグコード・TODO が残っていない
- [ ] Release ビルドで正常起動することを確認した

## 5. インストール・起動手順

### 5.1 ユーザー向け手順

1. ZIP ファイルを任意のフォルダへ展開する
2. `AppLauncher.exe` を実行する

**インストール操作は一切不要です。**

### 5.2 配置場所の推奨

| 場所 | 可否 | 備考 |
|---|---|---|
| `C:\Program Files\` 以下 | 非推奨 | 管理者権限が必要になる場合がある |
| ユーザーフォルダ（`%USERPROFILE%\AppData\` 等） | 推奨 | 設定ファイルが同じフォルダに生成されるため |
| デスクトップ・任意フォルダ | 可 | 書き込み権限があれば問題なし |

### 5.3 前提条件

- 実行ファイルの配置フォルダに **書き込み権限** が必要（`config/config.json` を自動生成するため）

## 6. 初回起動時に自動生成されるファイル

初回起動時（設定ファイルが存在しない場合）、以下のファイルが自動生成されます。

```
<AppLauncher.exe と同じフォルダ>/
└── config/
    └── config.json
```

| ファイル | 内容 |
|---|---|
| `config/config.json` | 全体設定・ページ設定・タイル設定を保存する JSON ファイル。初期値については[機能定義書 3.8](../function/アプリケーション機能定義.md#38-初回起動時の初期設定)を参照 |

設定ファイルの詳細フォーマットは [`../data/設定ファイルフォーマット.md`](../data/設定ファイルフォーマット.md) を参照してください。

## 7. アップデート手順

### 7.1 手順

1. アプリを終了する（タスクトレイアイコンを右クリック → 「終了」）
2. 旧バージョンの `AppLauncher.exe` を新バージョンに差し替える
3. `AppLauncher.exe` を起動する

### 7.2 設定の引き継ぎ

- `config/config.json` はアップデートしても**そのまま引き継がれます**
- exe の差し替えのみでアップデートが完了します

### 7.3 設定のリセット

設定を初期化したい場合は `config/config.json` を削除してからアプリを起動してください。

---

## 8. 配布後のフォルダ構成

### 8.1 初回起動前

```
AppLauncher.exe
```

### 8.2 初回起動後（通常使用時）

```
<配置フォルダ>/
├── AppLauncher.exe
└── config/
    └── config.json
```

> **注意**：`resources/` フォルダは現バージョンでは生成されません。アイコン・画像は exe に内包されています。将来のサウンド機能実装時に `resources/sounds/` フォルダが追加される予定です。
