# 配置位置数値定義書

このドキュメントは、ランチャー本体の UI コンポーネントに関する配置・サイズの数値を定義します。

> **レイアウト設定の読み込み**  
> ここに記載する数値はすべて設定ファイルから読み込む形式とします。  
> 各値は初期（デフォルト）値として扱い、設定ファイルが存在しない場合はここに記載の値で初期化されます。  
> 対応する設定ファイルの構造は `../data/設定ファイルフォーマット.md` の「レイアウト設定」セクションを参照してください。

## 1. タイル

| 項目 | 値 |
|---|---|
| 1×1 サイズ | 96 × 96 px |
| 2×2 サイズ | 200 × 200 px |
| タイル間マージン | 8 px |
| 角丸半径 | 20 px |
| ホバー時拡大率 | 1.13 倍（底面基準） |

**サイズ計算規則**  
n タイル分の辺の長さ = `96 × n + 8 × (n - 1)`

| タイル数 (n) | 計算式 | 合計 px |
|---|---|---|
| 1 | 96×1 + 8×0 | 96 |
| 2 | 96×2 + 8×1 | 200 |
| 3 | 96×3 + 8×2 | 304 |
| 4 | 96×4 + 8×3 | 408 |

## 2. タイル配置エリア

- 外周にマージンを持たない（タイル間のマージンのみ）。
- 配置エリアのサイズはタイル配置数（全体設定の縦・横タイル数）から算出される。

| 項目 | 値 |
|---|---|
| 外周マージン | 0 px（なし） |
| ランチャーフレーム左右端からの距離 | 20 px |

## 3. ページ名称エリア

ページ名称エリアの高さはフォントサイズの設定値により可変します。

| 項目 | 値 |
|---|---|
| ページ名称エリア高さ | `ceil( フォントサイズ(pt) × 4/3 )` px（フォントサイズ 16 pt の場合：22 px） |
| ページ名称エリア上マージン（フレーム上端から） | 8 px（固定） |
| ページ名称エリア下マージン（タイル配置エリア上端まで） | 8 px（固定） |
| ページ名称エリア左右マージン | 20 px（タイル配置エリアと揃える） |

|---|---|
| ボタンサイズ | 25 × 25 px |
| ボタン間マージン | 8 px |

### 設定画面遷移ボタン

| 項目 | 値 |
|---|---|
| ボタンサイズ | 32 × 32 px |
| 角丸半径 | 10 px |
| ランチャーフレーム右端からのマージン | 20 px |
| ボタン間マージン | 8 px |
| 表示方式 | 画像（検討中） |

### ボトムバー全体

| 項目 | 値 |
|---|---|
| ボトムバー上マージン（タイル配置エリア下端から） | 8 px（固定） |
| ボトムバー下マージン（ランチャーフレーム下端まで） | 8 px（固定） |
| 通常モード時のボトムバー高さ | 32 px（設定遷移ボタン高さに準拠） |

### 編集モード時の拡張

編集モードではページ管理コントロール行（行2）が追加されるため、ランチャーフレームが下方向に拡張されます。

| 項目 | 値 |
|---|---|
| 追加されるページ管理行の高さ | 25 px |
| 行間マージン | 8 px |
| 合計拡張量 | 25 + 8 = **33 px** |

編集モードを終了すると元のサイズに戻ります。

## 8. ウィンドウサイズの算出式

ウィンドウサイズは全体設定の「縦横タイル配置数」から逆算して決定されます。

### 変数定義

| 変数 | 内容 | デフォルト値 |
|---|---|---|
| `cols` | 横方向のタイル配置数（全体設定） | — |
| `rows` | 縦方向のタイル配置数（全体設定） | — |
| `tile_size` | タイル 1×1 の一辺サイズ | 96 px |
| `tile_margin` | タイル間マージン | 8 px |
| `side_margin` | タイル配置エリアの左右マージン（フレーム端から） | 20 px |
| `page_name_top` | ページ名称エリア上マージン（フレーム上端から） | 8 px |
| `page_name_bottom` | ページ名称エリア下マージン（タイル配置エリア上端まで） | 8 px |
| `page_name_h` | ページ名称エリアの高さ（フォントサイズによる可変値。16 pt の場合 22 px） | — |
| `bottom_top` | ボトムバー上マージン（タイル配置エリア下端から） | 8 px |
| `bottom_bottom` | ボトムバー下マージン（フレーム下端まで） | 8 px |
| `bottom_bar_h` | ボトムバーの高さ（通常モード：32、編集モード：65） | — |

### 算出式

```
タイル配置エリア幅  = tile_size × cols + tile_margin × (cols - 1)
タイル配置エリア高さ = tile_size × rows + tile_margin × (rows - 1)

ウィンドウ幅 = side_margin + タイル配置エリア幅 + side_margin
             = 2 × side_margin + tile_size × cols + tile_margin × (cols - 1)

ウィンドウ高さ = page_name_top + page_name_h + page_name_bottom
              + タイル配置エリア高さ
              + bottom_top + bottom_bar_h + bottom_bottom
```
