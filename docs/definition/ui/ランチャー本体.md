## 1. コンポーネント構成

ランチャー本体は以下のコンポーネントで構成されます。

```
ランチャー本体
├── ハンドル
└── ランチャーフレーム
    ├── ページ名称エリア
    ├── タイル配置エリア
    │   └── タイル（複数）
    └── ボトムバー
        ├── ページインジケーター
        └── 操作ボタン群
```

吸着方向が右端の場合の横並び配置イメージ：

```
[ ハンドル ][ ランチャーフレーム                        ]
            [   ページ名称エリア                        ]
            [   タイル配置エリア                        ]
            [   ボトムバー                              ]
                                               ← 右画面端
```

ハンドルは常に画面端と反対側（開口側）に配置されます。

---

## 2. ハンドル

- 細い縦長の矩形タブ。
- ランチャーフレームの画面端と逆側に隣接して配置される。
- 吸着方向に沿った辺の中央に配置される（例：右端吸着の場合、フレームの上下方向の中央）。
- 収納モード時はハンドルのみが画面上に表示される。このとき、ハンドルの位置は展開時と同じ位置（画面端の同じ高さ）を維持する。

---

## 3. ランチャーフレーム

- 角丸の矩形。
- グレー系の背景色を持つ外枠。
- 内部にタイル配置エリアとボトムバーを含む。
- OS のウィンドウタイトルバー・フレーム枠は非表示とする（フレームレスウィンドウ）。

**モード別の外枠スタイル**

| モード | 外枠スタイル |
|---|---|
| 通常モード | 実線（黒・2 px） |
| 通常モード（ピンモード ON） | 実線（黒・2 px） ＋ フレーム外周に白色の枠が追加される |
| 編集モード | 実線（黒・2 px）。編集モードはボタン色・ボトムバー構成・ピンモード枠により識別する |
| 収納モード | 非表示（ハンドルのみ表示） |

---

## 4. ページ名称エリア

- ランチャーフレーム内の最上部に配置される帯状の領域。
- 現在表示中のページ名をテキストで表示する。
- テキストは中央揃えで表示される。
- 左右マージンはタイル配置エリアと同じ値（各 20 px）とする。
- ページ名がエリアの幅を超える場合、末尾を省略記号（…）で切り捨てる。

---

## 5. タイル配置エリア

- ページ名称エリアの下に配置される領域。
- グリッド状にタイルを配置する。
- グリッドのサイズ（縦・横のタイル数）は全体設定で変更可能。

---

## 6. タイル

- 角丸の矩形。
- グリッド上の 1×1 ～ 4×4 の範囲でサイズを指定可能。
- タイル内のレイアウトは画像/アイコン表示位置の設定に従う（[機能定義書 3.5 参照](../function/アプリケーション機能定義.md#35-タイル詳細設定)）。
- 画像とテキストが同一領域に重なる場合（表示位置「中心」など）、テキストは常に画像の前面（上位 Z オーダー）に描画される。

**編集モードのタイルオーバーレイ**

編集モード中にタイルへマウスオーバーすると、タイル上にコントロールが重なって表示されます。

| コントロール | 配置 | 動作 |
|---|---|---|
| 編集ボタン | 右上 | タイル編集パネルを開く |
| 削除ボタン | 右側中段 | 削除確認ダイアログを表示する |
| コピーボタン | 左下 | タイルのコピーモードを開始する（詳細は[機能定義書 3.3 参照](../function/アプリケーション機能定義.md#33-タイル操作編集モード)） |
| サイズ変更領域 | 右下コーナー | ドラッグでタイルサイズを変更する |

## 7. ボトムバー

ランチャーフレーム下部に配置される操作バー。モードによって表示内容が変わる。

### 通常モード / 通常モード（ピンモード ON）

```
          [ ◎ ○ ○ ○ ]                          [ □ ]
        ページインジケーター（中央）          モード切替ボタン
```

| 要素 | 説明 |
|---|---|
| ページインジケーター | 現在のページを示すサークルボタン。**白色（不透明）** で描画される。現在ページは白塗りつぶし＋中心に小さなダークドット（◎）、その他は白アウトライン・中心透明（○）。クリックでそのページへ切り替える。ボトムバー内で**水平中央揃え**で配置する。編集モード中にタイルをドラッグしながらインジケーターにホバーすると 700 ms 後にそのページへ切り替わる |
| モード切替ボタン | 通常モード時はページ背景色（透過率 0 %）で表示、編集モード時はオレンジ色で表示される。押すと通常モード ↔ 編集モードを切り替える |

### 編集モード

編集モードのボトムバーは2行構成になります。
ページ管理コントロール（行2）の表示分だけ、**ランチャーフレームが下方向に拡張**されます。
タイル配置エリアのサイズは変わらず、フレームの下端のみが伸びます。

```
通常モード時のフレーム下端
┌──────────────────────────────────────────┐
│        [ ◎ ○ ○ ○ ]                [ □ ] │  ← 通常ボトムバー
└──────────────────────────────────────────┘
            ↑中央                     ↑右端

編集モード時のフレーム下端（下方向に拡張）
┌──────────────────────────────────────────┐
│        [ ◎ ○ ○ ○ ]        [アイコン群]  │
│        [ ← ][ ⊕ ][ ⊖ ][ → ]           │  ← フレームがここまで伸びる
└──────────────────────────────────────────┘
            ↑中央                     ↑右端
```

**行1 - ページインジケーター**

| 要素 | 説明 |
|---|---|
| `◎ ○ ○ ○` | 現在ページは塗りつぶし（◎）、その他は空丸（○）で表示 |

**行1 - 設定遷移ボタン群（右寄せ）**

2つのボタンが横並びで表示されます。

| ボタン | 動作 |
|---|---|
| ページ編集ボタン | ページ編集モードへ遷移する |
| モード切替ボタン | 編集モード → 設定モードへ切り替える（オレンジ色で表示） |

- 最終的にはアイコン表示とする予定です（画像内のテキスト表記は仮のものです）。
- 全体設定は設定モードの仮想ページにあるタイルから遷移するため、編集モードのボトムバーには表示しない。

**行2 - ページ管理コントロール**

ページ管理コントロール（← ⊕ ⊖ →）は**水平中央揃え**で配置します。

| ボタン | 説明 |
|---|---|
| `←` | 選択中ページの順序を左方向のページと入れ替える。選択中ページが最も左の場合は何も行わない（ループしない） |
| `⊕` | 新しいページを追加する。フォーカス中ページの配色設定を継承する（タイルは継承しない） |
| `⊖` | 選択中ページを削除する。タイルが未配置の場合のみ実行可能 |
| `→` | 選択中ページの順序を右方向のページと入れ替える。選択中ページが最も右の場合は何も行わない（ループしない） |

- ページ数の上限は **10** です。上限に達した場合、`⊕` ボタンは非活性になります。
- ページ数の最小値は **1** です。ページが 1 つしかない場合、`⊖` ボタンは非活性になります。
- ページインジケーターと設定遷移ボタン群が重なる幅になった場合、ページインジケーターのサイズを縮小して収めます。縮小の下限はデフォルトサイズの 50 % です。

## 8. 設定画面（共通レイアウト）

タイル編集モード・ページ編集モード・全体設定モードでは、ランチャー本体と**同一の OS ウィンドウ内**の描画内容を設定画面に切り替える形で表示します（新しいウィンドウは開きません）。ハンドルは引き続き表示されます。

### レイアウト構成

```
┌──────────────────────────────────────────┐
│ [プレビューエリア]       モード名ラベル   │
│                                          │
│ ▲ セクション名                           │
│     項目1    [入力フィールド]            │
│     項目2    [入力フィールド]            │
│                                          │
│ ▼ セクション名（折りたたみ時）           │
│                                          │  ↕スクロールバー
│                        [キャンセル][OK]  │
└──────────────────────────────────────────┘
```

### プレビューエリア

- 左上に配置される。サイズはタイル 2×1 分（幅 200 px × 高さ 96 px）とする。
- **色・透過率が変更できる設定項目が存在する場合のみ表示される。**
- 設定値を変更すると、OK を押さずとも即座にプレビューへ反映される。
- 実際のタイル・ページへの反映は「OK」ボタン押下時に行われる。

### セクション

- 設定項目は関連ごとにセクションに分類される。
- 各セクションにはヘッダーと折りたたみボタンを設置する。
- 折りたたみボタンを押すとセクション内の項目を非表示にできる。

### スクロールバー

- 設定項目がウィンドウの表示領域を超える場合に、右側にスクロールバーを表示する。

### OK / キャンセルボタン

- 画面下部に配置する。
- OK：設定を保存・反映して編集モードへ戻る。
- キャンセル：設定を破棄して編集モードへ戻る。

### UI要素の配色

スクロールバー・ボタン・折りたたみボタンの色は、選択中ページの背景色を基準に以下の手順で自動計算する。

1. ページ背景色の RGB を HSL 色空間に変換する
2. 明度（L）を基準に調整する：
   - L ≥ 50 % の場合：L を 15 ポイント下げる（暗い方向へ）
   - L < 50 % の場合：L を 15 ポイント上げる（明るい方向へ）
3. 彩度（S）を 5 ポイント下げる（下限 0）
4. 透過率は 0 %（完全不透明）固定とする

> **参考（想定図での値）**  
> ページ背景色 gray = `#8C9BAB`（HSL: 207°, 13%, 62%）の場合  
> → L: 62 - 15 = 47%、S: 13 - 5 = 8%  
> → UI 要素色: HSL(207°, 8%, 47%) ≈ `#6D7880`

### カラー選択方式

アプリ内でカラーを選択する項目はすべてプルダウン方式とする。

- プルダウンの各選択肢には、対応する色のサンプル（カラーブロック等）を横に表示し、視覚的に色が判断できるようにする。
- 選択肢はカラーパレットに定義された色一覧から生成する（[機能定義書 3.6 カラーパレット参照](../function/アプリケーション機能定義.md#36-カラーパレット)）。

## 9. モード別外観

### 通常モード（展開時）

- ランチャーフレームが実線で表示される。
- ボトムバーにページインジケーターとモード切替ボタンが表示される。

### 通常モード・ピンモード ON（展開時）

- ランチャーフレームの外周に白色の枠が追加される。
- ボトムバーの表示内容は通常モードと同一。

### 編集モード（展開時）

- ランチャーフレームの外枠スタイルは通常モードと同じ実線（黒・2 px）。編集モードはモード切替ボタンのオレンジ色表示・ボトムバー行2の追加・ピンモード枠の表示により識別できる。
- ボトムバーが2行構成になり、その分だけフレームが下方向に拡張される。
  - 1行目：ページインジケーター（左）＋ 設定遷移ボタン群（右）
  - 2行目：ページ管理コントロール（← ⊕ ⊖ →）
- タイル配置エリアのサイズは変化しない。

### 収納モード

- ランチャーフレームは画面端の外側へ隠れる。
- ハンドルのみが画面端に表示される。
