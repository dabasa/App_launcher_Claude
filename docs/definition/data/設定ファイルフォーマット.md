## 1. ファイル形式

**JSON**（ファイル名：`config.json`）

- 文字コード：UTF-8（BOM なし）
- インデント：スペース 2 文字
- キー命名：lowerCamelCase

---

## 2. 保存先

アプリケーション本体（.exe）が存在するフォルダ内に以下の構成でファイルを管理します。

```
<exe フォルダ>/
├── <AppName>.exe
├── config/               ← 設定ファイル（起動時に生成）
│   └── config.json
└── resources/            ← アプリリソース（ビルド時に配置）
    ├── icons/
    │   └── app.ico       ← アプリアイコン（exe・トレイ共通）
    └── sounds/           ← UIサウンド
```

`resources/` フォルダはビルド時に `src/resources/` の内容をコピーして配置します。`config/` フォルダはアプリ初回起動時に自動生成されます。

### アイコンの適用仕様

| ファイル | コンパイル時の用途 | 実行時の用途 |
|---|---|---|
| `resources/icons/app.ico` | exe ファイルに埋め込むアプリケーションアイコン | タスクトレイアイコン |

## 3. データ構造

`config.json` のトップレベル構造：

```json
{
  "global":      { ... },
  "layout":      { ... },
  "pages":       [ ... ],
  "customColor": "#3A7BD5",
  "tileStyles":  [ ... ],
  "pageStyles":  [ ... ]
}
```

| キー | 型 | 説明 |
|---|---|---|
| `global` | object | アプリ全体設定（§3.1） |
| `layout` | object | レイアウト数値（§3.4） |
| `pages` | array | ページ設定の配列（§3.2） |
| `customColor` | string? | カスタム色（hex 文字列または `null`）（§3.5） |
| `tileStyles` | array | タイルカラースタイルの配列（§3.6） |
| `pageStyles` | array | ページカラースタイルの配列（§3.7） |

### 3.1 アプリ全体設定

アプリ全体に関わる設定（全体設定モードで変更可能な項目）を保存します。

| 項目 | 対応する機能定義 |
|---|---|
| タスクトレイ常駐 | 全体設定モード |
| Windows 起動時の自動起動 | 全体設定モード |
| タイル配置数（縦・横） | 全体設定モード |
| ページ名フォントサイズ | 全体設定モード |
| 吸着位置 | 全体設定モード |
| 収納待ち時間 | 全体設定モード |

**JSON フォーマット**

```json
"global": {
  "taskTrayResident": true,
  "startWithWindows": false,
  "alwaysOnTop": true,
  "tileCountCols": 6,
  "tileCountRows": 4,
  "pageNameFontSizePt": 16,
  "snapPosition": "right",
  "snapMonitor": 1,
  "storageDelayMs": 1000,
  "animationDurationMs": 300,
  "savedWindowTop": null,
  "savedWindowLeft": null
}
```

| キー | 型 | 値の仕様 |
|---|---|---|
| `taskTrayResident` | boolean | `true` / `false` |
| `startWithWindows` | boolean | `true` / `false` |
| `alwaysOnTop` | boolean | `true` / `false`。常に最前面に表示するか |
| `tileCountCols` | integer | 4 〜 16 |
| `tileCountRows` | integer | 4 〜 16 |
| `pageNameFontSizePt` | integer | 6 〜 72 |
| `snapPosition` | string | `"right"` / `"left"` / `"top"` / `"bottom"` |
| `snapMonitor` | integer | 1 以上の整数。1 が主モニター、2 以降がサブモニター |
| `storageDelayMs` | integer | 0 〜 3000 |
| `animationDurationMs` | integer | 0 〜 1000。収納・展開アニメーション時間（ms） |
| `savedWindowTop` | number? | `null` または実数。再起動時に復元するウィンドウ上端座標（左右吸着用） |
| `savedWindowLeft` | number? | `null` または実数。再起動時に復元するウィンドウ左端座標（上下吸着用） |

### 3.2 ページ設定

ページごとの設定（ページ編集モードで変更可能な項目）を保存します。

| 項目 | 対応する機能定義 |
|---|---|
| ページ背景色 | ページ編集モード |
| ページ背景の透過率 | ページ編集モード |
| ハンドル色 | ページ編集モード |
| ハンドルの透過率 | ページ編集モード |
| ピンモード枠色 | ページ編集モード |
| ピンモード枠透過率 | ページ編集モード |

**JSON フォーマット**（`pages` 配列の各要素）

```json
{
  "name": "ページ1",
  "backgroundColor": "gray",
  "backgroundOpacity": 30,
  "handleColor": "gray",
  "handleOpacity": 20,
  "pinFrameColor": "white",
  "pinFrameOpacity": 50,
  "tiles": [ ... ]
}
```

| キー | 型 | 値の仕様 |
|---|---|---|
| `name` | string | ページ名（文字数制限なし） |
| `backgroundColor` | string | カラーパレット名（例：`"gray"`） |
| `backgroundOpacity` | integer | 0 〜 90 |
| `handleColor` | string | カラーパレット名 |
| `handleOpacity` | integer | 0 〜 90 |
| `pinFrameColor` | string | カラーパレット名 |
| `pinFrameOpacity` | integer | 0 〜 90 |
| `tiles` | array | タイル設定の配列（§3.3 参照） |

### 3.3 タイル設定

タイルごとの設定（タイル編集モードで変更可能な項目）を保存します。

| 項目 | 対応する機能定義 |
|---|---|
| タイトル | タイル詳細設定 基本セクション |
| 種類 | タイル詳細設定 基本セクション |
| システム情報設定（system タイルのみ） | タイル詳細設定 システム情報セクション |
| パス / URL | タイル詳細設定 起動セクション |
| 引数 | タイル詳細設定 起動セクション |
| 作業フォルダ | タイル詳細設定 起動セクション |
| カラー | タイル詳細設定 見た目セクション |
| 透過率 | タイル詳細設定 見た目セクション |
| フォント名 | タイル詳細設定 見た目セクション |
| フォントサイズ | タイル詳細設定 見た目セクション |
| フォントカラー | タイル詳細設定 見た目セクション |
| 画像 / アイコンの URL / パス | タイル詳細設定 見た目セクション |
| 画像 / アイコン表示位置 | タイル詳細設定 見た目セクション |
| 画像 / アイコンを透過させる | タイル詳細設定 見た目セクション |
| タイルサイズ（縦・横） | タイル配置情報 |
| タイル配置位置（グリッド座標） | タイル配置情報 |

> **グリッド座標系**：原点は左上（0, 0）。右方向を X 軸正方向、下方向を Y 軸正方向とします。インデックスは 0 始まりです。

**JSON フォーマット**（`tiles` 配列の各要素）

```json
{
  "col": 0,
  "row": 0,
  "colSpan": 1,
  "rowSpan": 1,
  "type": "app",
  "title": "Chrome",
  "path": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe",
  "args": "",
  "workDir": "",
  "color": "blue",
  "opacity": 20,
  "fontName": "",
  "fontSizePt": 16,
  "autoFontSize": false,
  "fontColor": "white",
  "imagePath": "",
  "imagePosition": "top",
  "imageTransparent": false
}
```

`type` が `"system"` の場合のみ、以下の `systemInfo` オブジェクトを追加します。

```json
{
  "col": 0,
  "row": 0,
  "colSpan": 1,
  "rowSpan": 1,
  "type": "system",
  "title": "CPU",
  "color": "gray",
  "opacity": 0,
  "fontName": "",
  "fontSizePt": 12,
  "fontColor": "white",
  "imagePath": "",
  "imagePosition": "top",
  "imageTransparent": false,
  "systemInfo": {
    "category": "usage",
    "deviceType": "cpu",
    "target": "CPU(0)",
    "displayFormat": "circle",
    "mainColor": "blue",
    "accentColor": "orange",
    "backgroundAccent": "red",
    "threshold": 80,
    "clickAction": "refresh",
    "updateIntervalMs": 60000
  }
}
```

| キー | 型 | 値の仕様 |
|---|---|---|
| `col` | integer | グリッド列（0 始まり） |
| `row` | integer | グリッド行（0 始まり） |
| `colSpan` | integer | 横方向タイル数（1 〜 4） |
| `rowSpan` | integer | 縦方向タイル数（1 〜 4） |
| `type` | string | `"app"` / `"url"` / `"folder"` / `"webview"` / `"system"` |
| `title` | string | タイル表示ラベル |
| `path` | string | パス または URL（`system` は省略） |
| `args` | string | 起動引数（`app` のみ。`{drop}` 構文使用可） |
| `workDir` | string | 作業フォルダ（`app` のみ） |
| `color` | string | カラーパレット名 |
| `opacity` | integer | 0 〜 90 |
| `fontName` | string | フォント名（空文字はシステムデフォルト） |
| `fontSizePt` | integer | 6 〜 72 |
| `autoFontSize` | boolean | `true` でフォントサイズ自動調整 ON |
| `fontColor` | string | カラーパレット名 |
| `imagePath` | string | 画像 / アイコンのパスまたは URL（空文字は未設定） |
| `imagePosition` | string | `"top"` / `"bottom"` / `"left"` / `"right"` |
| `imageTransparent` | boolean | `true` / `false` |
| `systemInfo.category` | string | `"os"` / `"storage"` / `"usage"` / `"top_process"` |
| `systemInfo.deviceType` | string | `"cpu"` / `"memory"` / `"gpu"` / `"lan"`（`usage` のみ） |
| `systemInfo.target` | string | 対象デバイス識別子（例：`"CPU(0)"`） |
| `systemInfo.displayFormat` | string | `"text"` / `"circle"` / `"bar"` |
| `systemInfo.mainColor` | string | カラーパレット名 |
| `systemInfo.accentColor` | string | カラーパレット名 |
| `systemInfo.backgroundAccent` | string | カラーパレット名 |
| `systemInfo.threshold` | integer | 0 〜 100（%） |
| `systemInfo.clickAction` | string | `"refresh"` |
| `systemInfo.updateIntervalMs` | integer | 100 〜 3,600,000 |

### 3.5 カスタム色

ユーザーが任意に設定できる 1 件のカスタムカラーです。

**JSON フォーマット**

```json
"customColor": "#3A7BD5"
```

| キー | 型 | 値の仕様 |
|---|---|---|
| `customColor` | string? | hex 文字列（例：`"#3A7BD5"`）または `null`（未設定） |

- 未設定時は `null`。カラー選択プルダウンの「カスタム」項目は表示されるが値なし扱い。
- カラーピッカーで別の色を設定すると上書きされる（1 件固定）。

### 3.6 タイルカラースタイル

タイルのカラー設定をまとめたプリセットスタイルの配列です。

**JSON フォーマット**

```json
"tileStyles": [
  { "name": "80年代サイバーパンク風", "isDefault": true,  "color": "#00E5FF", "opacity": 10, "fontColor": "#EAFBFF" },
  { "name": "カラフルゆるふわ配色",   "isDefault": true,  "color": "#A8D8FF", "opacity": 20, "fontColor": "#5A5A5A" },
  { "name": "ブルー系メイン配色",     "isDefault": true,  "color": "#3B82F6", "opacity": 20, "fontColor": "#E5F0FF" },
  { "name": "ブラック系メイン配色",   "isDefault": true,  "color": "#1A1A1A", "opacity":  5, "fontColor": "#F2F2F2" },
  { "name": "ブラウン系メイン配色",   "isDefault": true,  "color": "#6B4F3A", "opacity": 10, "fontColor": "#F6E9DA" }
]
```

| キー | 型 | 値の仕様 |
|---|---|---|
| `name` | string | スタイル名（ユーザー作成スタイルはユーザーが任意に命名） |
| `isDefault` | boolean | `true` = デフォルトスタイル（削除不可）、`false` = ユーザー作成スタイル |
| `color` | string | タイル背景色（hex 文字列） |
| `opacity` | integer | 背景透過率（0 〜 90 %） |
| `fontColor` | string | フォントカラー（hex 文字列） |
