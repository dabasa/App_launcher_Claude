## 1. 概要

このドキュメントは、アプリランチャーの実装機能を定義します。

**実装技術**：WPF（C# / .NET 8）。詳細は [`../implementation/技術スタック.md`](../implementation/技術スタック.md) を参照。

## 2. アプリケーション状態定義

アプリケーションは以下に示す状態を遷移しながら動作します。

### 2.1 通常モード

アプリランチャーとして動作する基本状態です。

**遷移条件**
- アプリ起動時に初期状態としてこのモードで起動します。
- 編集モードでモード切替ボタンを押すと、このモードへ戻ります。
- 収納モード時にハンドル部分へマウスオーバーすると、このモードへ遷移します。

- ランチャーのドラッグによる位置移動は、通常モード（ピンモード ON/OFF 問わず）で行えます。
- 収納モードへ移行できるのは、このモードのみです。
- 吸着先の画面端とランチャー本体の間に生じる隙間にカーソルがある場合は、本体にフォーカスがあるものとして扱い、自動収納を抑制します。（収納 → 展開の無限ループを防止するための措置）

### 2.2 通常モード（ピンモード ON）

収納モードへの移行を禁止するモードです。

**遷移条件**
- 通常モードで、アプリのタイル・ボタン外の領域をダブルクリックするとピンモードが ON になります。
- 右クリックメニューからピンモードを選択することでも切り替えられます。
- ピンモード ON の状態で同じ操作を行うと、ピンモードが OFF になり通常モードへ戻ります。
- 編集モードから通常モードへ戻る際、ユーザーが事前にピンモードを設定していた場合はピンモード ON の状態が維持されます。

- ドラッグによる位置移動は通常モード（ピンモード OFF）と同様に可能です。
- ユーザーが任意に切り替えを行えます。
- 自動収納されると困る場面での活用を想定しています。

### 2.3 編集モード

タイル・ページ・全体設定の編集が行える状態です。

**遷移条件**
- 通常モード（ピンモード ON/OFF 問わず）でモード切替ボタンを押すとこのモードへ遷移します。
- 編集モードで再びモード切替ボタンを押すと通常モードへ戻ります。このとき、ユーザーが手動でピンモードを設定していた場合を除きピンモードは解除されます。

- 編集モードに移行すると、自動的にピンモードが ON になります。このとき、ピンモード枠（白枠）も表示されます。
- 以下の操作が可能になります。
  - タイルの追加・削除・移動・編集
  - ページの追加・削除・移動・編集
  - 全体設定の変更
  - ページ名称エリアをクリックすることでページ名を直接入力・変更可能
- ページを削除した場合、削除されたページの左隣のページへ移動します（削除されたページが最も左のページだった場合は、右隣のページへ移動します）。

**ページ名のインライン編集**

- 文字数の上限なし。
- キャンセル操作なし（入力を中断する手段は提供しない）。
- ページを切り替える（ページインジケーターのクリック等）場合、または編集モードを抜ける（タイル編集モード・ページ編集モード・全体設定モードへ遷移する、または通常モードへ戻る）際に、入力中の文字列でページ名を確定する。

### 2.4 タイル編集モード

タイルの詳細設定を操作できる状態です。

**遷移条件**
- 編集モードで配置済みタイル上の編集ボタンを押すとこのモードへ遷移します。
- 「OK」ボタンを押すと設定が保存・反映され、編集モードへ戻ります。
- 「キャンセル」ボタンを押すと設定を破棄し、編集モードへ戻ります。

- タイルの見た目（色・アイコンなど）や動作内容の細かい設定が可能です。

### 2.5 ページ編集モード

ページ個別の設定を操作できる状態です。

**遷移条件**
- 編集モード時に表示されるページ編集ボタンを押すとこのモードへ遷移します。
- 「OK」ボタンを押すと設定が保存・反映され、編集モードへ戻ります。
- 「キャンセル」ボタンを押すと設定を破棄し、編集モードへ戻ります。

- ランチャーは複数のページで構成されており、各ページにタイルを配置できます。
- ページの見た目はページごとに独立して設定・管理されます。

**設定項目**

| 設定項目 | 説明 |
|---|---|
| ページ背景色 | ページ背景の色 |
| ページ背景の透過率 | ページ背景の透明度（[共通仕様参照](#4-共通仕様)） |
| ハンドル色 | ハンドルの色 |
| ハンドルの透過率 | ハンドルの透明度（[共通仕様参照](#4-共通仕様)） |
| ピンモード枠色 | ピンモード ON 時に表示される枠の色 |
| ピンモード枠透過率 | ピンモード ON 時の枠の透明度（[共通仕様参照](#4-共通仕様)） |

### 2.6 全体設定モード

アプリ全体に関わる設定を行う状態です。

**遷移条件**
- 編集モード時に表示される全体設定ボタンを押すとこのモードへ遷移します。
- 「OK」ボタンを押すと設定が保存・反映され、編集モードへ戻ります。
- 「キャンセル」ボタンを押すと設定を破棄し、編集モードへ戻ります。

| 設定項目 | 説明 |
|---|---|
| タスクトレイ常駐 | ON/OFF の切り替え |
| Windows 起動時の自動起動 | ON/OFF の切り替え |
| タイル配置数（縦・横） | 縦・横それぞれ独立して設定可能（各 4 ～ 16）。この値によりアプリ本体のサイズが変動する |
| タイル間マージン | タイル同士の間隔（0 ～ 30 px） |
| ページ名フォントサイズ | ページ名テキストのフォントサイズ（[共通仕様参照](#4-共通仕様)） |
| 吸着位置 | 画面端への吸着方向（上・右・下・左） |
| 吸着先モニター | 吸着するモニターを番号で選択（1 = 主モニター、2 以降 = サブモニター）。接続中のモニター数に応じた選択肢を表示する |
| 収納待ち時間 | マウスオーバーがない状態が続いてから収納モードへ移行するまでの時間（0 ～ 3000 ms、デフォルト：1000 ms）。0 ms の場合はマウスオーバーが外れた瞬間に即座に収納される |

> **タイル配置数の縮小制限**：縦・横いずれかを縮小する場合、配置済みタイルが占有する最大座標を下回る方向への縮小はできません。

### 2.7 収納モード

ランチャー本体が画面端へ収納され、ハンドル部分のみが画面上に表示されている状態です。

**遷移条件**
- ピンモードが OFF の状態で、アプリへのマウスオーバーがない状態が収納待ち時間（デフォルト：1000 ms）続くと、このモードへ移行します。収納待ち時間が 0 ms の場合は、マウスオーバーが外れた瞬間に即座に移行します。
- 収納中にハンドル部分へマウスオーバーすると収納が解除され、通常モードへ戻ります。

**動作仕様**
- 収納先は吸着方向に応じて変わります。（例：右端吸着中であれば、右画面端へ収納）
- 収納中はハンドル部分のみが画面内に表示されます。
- 通常モード → 収納モード、および収納モード → 通常モードの移行時、ランチャー本体が画面端へ入り込む・出てくるアニメーションが再生されます。
- 収納・収納解除のアニメーションはそれぞれ 1 秒で完了します。
- 画面下端に吸着している場合、タスクバーの上端を画面端として扱い、タスクバーの下側へ潜り込む形で収納されます。

## 3. 機能仕様

### 3.1 画面吸着

- アプリは画面端から一定距離を保った位置に吸着し、それ以上離れる方向には移動できません。
- 移動可能な方向は、吸着面に平行な方向のみです。（右端吸着の場合、上下方向のみスライド可能）
- アプリ上の任意の箇所をマウスドラッグすることで移動できます。
- ドラッグ中は、マウスの移動量に比例した自然な速度で追従します。（感覚から乖離した移動速度は禁止）
- 吸着方向は**上・右・下・左**の 4 方向です。
- 初回起動時は画面右端の中央に吸着した状態で起動します。
- 全体設定で吸着位置を変更した場合、変更は直後にアニメーションなしで反映されます（瞬間移動）。
- 画面端とハンドル外端の間には一定の距離を設けます（デフォルト：20 px）。
- ランチャーは常に他のウィンドウの最前面に表示されます（alwaysOnTop）。
- マルチモニター環境では、サブモニターの画面端にも吸着できます。吸着先のモニターは**全体設定モード**で番号により選択します（1 = 主モニター、2 以降 = サブモニター）。接続中のモニター数が選択肢の上限となります。

### 3.2 タイル

- タイル配置可能領域内で、タイルの作成・移動・サイズ変更が行えます。
- タイルサイズは **1×1（最小）〜 4×4（最大）** の範囲で設定できます。
- 全体設定モードで指定した縦横のタイル配置数に応じて、アプリ本体のサイズが変動します。
- タイルには以下の表示設定が可能です。
  - 背景色・透明度の設定
  - 画像・アイコンの表示
- タイル上にマウスカーソルを乗せると、ホバーアニメーションが再生されます（通常モードのみ。底面を基準に 1.13 倍に拡大）。編集モード中はホバーアニメーションは発生しません。
- ホバーアニメーションで拡大したタイルは、隣接する他のタイルの上に重なって表示されます（他のタイルは移動しません）。
- 画像ファイルとして GIF が設定されている場合、GIF アニメーションをループ再生します。非表示ページに配置されたタイルの GIF アニメーションは一時停止し、ページが再表示された際に再開します。
- ページの切り替えはアニメーションなしで即座に切り替わります。

### 3.3 タイル操作（編集モード）

**タイルの新規作成（クリック）**

1. タイル未配置領域にカーソルを移動すると、1×1 サイズの配置プレビュー枠が表示されます。
2. プレビュー枠内でクリックすると、以下のデフォルト設定で新規タイルが作成されます。

| 設定項目 | デフォルト値 |
|---|---|
| 種類 | `app` |
| パス / 引数 | 未設定 |
| 背景色 | blue（`#4A90D9`） |
| 透過率 | 20 % |
| フォントサイズ | 16 pt |
| フォントカラー | white（`#F0F0F0`） |
| 画像 / アイコン表示位置 | 上 |

**タイルの新規作成（ドラッグ＆ドロップ）**

- 対応ファイル形式：実行ファイル（.exe）、スクリプトファイル、HTML ファイル、ショートカット（.lnk）、画像ファイル
- タイル未配置領域へドラッグすると配置プレビュー枠が表示され、ドロップするとファイルに応じた設定が自動登録されたタイルが作成されます。
- 見た目のデフォルト値（背景色・透過率・フォントサイズ・フォントカラー・画像表示位置）はクリック作成時と同じ値を適用します。

**ドロップファイルとタイル種別のマッピング**

| ドロップしたファイル種別 | 作成されるタイル種別 | 自動設定される内容 |
|---|---|---|
| 実行ファイル（.exe） | `app` | パスに .exe のパスを設定 |
| ショートカット（.lnk） | `app` | パスにリンク先の実行ファイルパスを設定 |
| スクリプトファイル（.bat / .ps1 / .vbs 等） | `app` | パスにスクリプトファイルのパスを設定 |
| HTML ファイル（.html / .htm） | `app` | パスに HTML ファイルのパスを設定（ブラウザで起動） |
| 画像ファイル（.png / .jpg / .gif 等） | `app` | 画像 / アイコンパスに画像ファイルのパスを設定。画像 / アイコン表示位置を「上」に設定 |

**配置済みタイルの操作**

配置済みタイル上でマウスオーバーすると、以下のコントロールが表示されます。

| コントロール | 動作 |
|---|---|
| 編集ボタン | タイル編集モードを開く |
| 削除ボタン | 確認ダイアログを表示する |
| サイズ変更領域 | 右下コーナーをドラッグして 4×4 以内の任意サイズへ変形。変形中は配置プレビュー枠が表示され、他のタイルと重なる位置には配置不可 |

**タイル削除の確認ダイアログ**

- ランチャーフレームの中央に確認ダイアログを表示する。
- ダイアログ背後はランチャーの直前の画面が透けて見えるオーバーレイを表示する。
- ダイアログはデフォルトカラー（gray：`#8C9BAB`）で描画する。
- ダイアログサイズ：300 × 140 px
- 表示内容：「タイルを削除しますがよろしいですか？」
- ボタン：「OK」（削除実行）・「キャンセル」（削除中止）

**タイルの移動**

- サイズ変更領域・ボタン以外の箇所をドラッグすると、タイルを移動できます。
- ドラッグ中はカーソル位置にタイルサイズの配置プレビュー枠が表示されます。
- 他のタイルが占有している領域には移動不可です。
- 同じサイズのタイル上でドロップすると、2 つのタイルの位置が入れ替わります。入れ替え元・入れ替え先のどちらかが D&D 専用タイルの場合も入れ替えを行います。
- 異なるサイズのタイル上でドロップした場合は何も行いません（移動キャンセル）。
- ドラッグ中は、マウスの移動量に比例した自然な速度で追従します。

### 3.4 タイルの種類

| 種別 | 説明 |
|---|---|
| `app` | 指定したアプリケーションを起動する |
| `url` | 指定した URL をブラウザで開く |
| `folder` | 指定したパスのフォルダを開く |
| `webview` | 指定したパスまたは URL の内容をタイル内に表示する |
| `system` | システム情報を取得してタイル内に表示する |

#### 種別ごとのクリック動作

**`app`**
- パスに指定されたアプリケーションを起動する。
- 引数が設定されている場合はコマンドライン引数として渡す。
- 作業フォルダが設定されている場合はそのフォルダをカレントディレクトリとして起動する。
- 引数フィールドに `{drop}` 構文が含まれる場合は D&D 専用タイルとして動作し、クリックによる起動は行わない（[詳細は 3.5 D&D 構文を参照](#35-タイル詳細設定)）。

**`url`**
- 指定した URL をデフォルトブラウザで開く。

**`folder`**
- 指定したパスのフォルダをエクスプローラーで開く。

**`webview`**
- 指定した URL またはローカルの HTML ファイルをタイル内に表示する。
- クリック時の動作は表示している HTML 側の実装に委ねる。
- 通常モードにおいて、タイル内コンテンツへのマウス操作（クリック・スクロール・テキスト入力等）が可能。
- ホバーアニメーション時はタイル内コンテンツごと 1.13 倍に拡大される。
- 非表示ページに配置された場合も、コンテンツのロードは継続されます。

**`system`**
- システム情報を取得してタイル内に表示する。
- クリック時の動作はタイル詳細設定のシステム情報セクション内「クリック動作」の設定内容に従う。

### 3.5 タイル詳細設定

#### 基本セクション

| 設定項目 | 説明 |
|---|---|
| タイトル | タイルに表示するラベル |
| 種類 | タイルの種別（[3.4 参照](#34-タイルの種類)） |

#### システム情報セクション（種類が `system` の場合のみ表示）

情報カテゴリの選択内容によって、各設定項目の有効/無効が変わります。

| 設定項目 | 説明 |
|---|---|
| 情報カテゴリ | 表示するシステム情報の分類 |
| デバイス種別 | 対象デバイスの種別（カテゴリによって選択可否が変わる） |
| 対象 | 情報取得の対象（カテゴリによって選択可否が変わる） |
| 表示形式 | 情報の表示スタイル（カテゴリによって選択肢が変わる） |
| メインカラー | テキスト・グラフの主要表示色 |
| アクセント | 使用率が基準値を超えた際のグラフ色（カテゴリによって選択可否が変わる） |
| 背景アクセント | 使用率が基準値を超えた際のタイル背景色（カテゴリによって選択可否が変わる） |
| 基準値 | アクセント適用のしきい値（カテゴリによって選択可否が変わる） |
| クリック動作 | タイルクリック時のアクション。現時点では「表示更新」のみ（データを再取得し描画を更新する） |
| 更新間隔 | 情報を自動更新する間隔（ms 単位）。最小値：100 ms、最大値：3,600,000 ms（60 分）、デフォルト：60,000 ms（1 分） |

非表示ページに配置された `system` タイルの自動更新タイマーは一時停止します。ページが再表示された際は即時データ取得を行い、その後タイマーを再開します。

##### 情報カテゴリ：OS情報

OS の名称・バージョンを表示します。

| 設定項目 | 内容 |
|---|---|
| デバイス種別 | 選択不可 |
| 対象 | 選択不可 |
| 表示形式 | 「テキスト表示」のみ |
| メインカラー | 名称・バージョンのテキスト色 |
| アクセント | 選択不可 |
| 背景アクセント | 選択不可 |
| 基準値 | 選択不可 |
| クリック動作 | 「表示更新」のみ |

##### 情報カテゴリ：ストレージ

ドライブレター・ストレージ容量・空き容量を表示します。

| 設定項目 | 内容 |
|---|---|
| デバイス種別 | 選択不可 |
| 対象 | ドライブレターを選択 |
| 表示形式 | 「テキスト表示」または「円形グラフ」 |
| メインカラー | ドライブ情報のテキスト色 |
| アクセント | 選択可 |
| 背景アクセント | 選択可 |
| 基準値 | 選択可 |
| クリック動作 | 「表示更新」のみ |

- 円形グラフ形式の場合、グラフの下にドライブレターを表示します。

##### 情報カテゴリ：使用率

対象デバイスの使用率を表示します。

| 設定項目 | 内容 |
|---|---|
| デバイス種別 | CPU / メモリ / GPU / LAN から選択（LAN は帯域使用率 % を表示） |
| 対象 | デバイスが複数存在する場合、`CPU(0)` / `CPU(1)` のような形式で個別選択可 |
| 表示形式 | 「テキスト表示」または「円形グラフ」 |
| メインカラー | テキスト・グラフの主要表示色 |
| アクセント | 選択可 |
| 背景アクセント | 選択可 |
| 基準値 | 選択可（基準となる使用率の % を数値入力） |
| クリック動作 | 「表示更新」のみ |

- テキスト形式では、デバイス名と使用率を表示します。
- 円形グラフ形式では、使用率のグラフの下にデバイス名称を表示します。

##### 表示形式の種類

**テキスト表示**
- 対象デバイスの情報をテキストで表示します。
- すべての情報カテゴリで選択可能です。

**円形グラフ**
- タイル内に使用率を円形グラフで表示します。
- 情報カテゴリが「ストレージ」または「使用率」の場合に選択可能です。
- メインカラー：グラフ内の使用率部分に適用。
- アクセントカラー：使用率が基準値を超えた際に、グラフ内の使用率部分に適用。
- 背景アクセント：使用率が基準値を超えた際に、タイル背景色に適用。
- 基準値：アクセント・背景アクセントが適用されるしきい値（% を数値入力）。

#### 起動セクション

種別によって表示される項目が異なります。

| 設定項目 | `app` | `url` | `folder` | `webview` | `system` |
|---|---|---|---|---|---|
| パス / URL | ○ | ○ | ○ | ○ | × |
| 引数 | ○ | × | × | × | × |
| 作業フォルダ | ○ | × | × | × | × |

| 設定項目 | 説明 |
|---|---|
| パス / URL | 起動対象のファイルパスまたは URL |
| 引数 | 起動時に渡すコマンドライン引数（`app` のみ） |
| 作業フォルダ | 起動時のカレントディレクトリ（`app` のみ） |

**D&D 構文（`app` 専用）**

引数フィールドに以下の構文を含めることで、タイルへドラッグ＆ドロップされたファイルをアプリへ引数として渡すことができます。

| 構文 | 説明 |
|---|---|
| `{drop}` | ドロップされたファイルまたはフォルダのパスに置き換えられる。パスは単一・複数問わず常に引用符で囲む。複数アイテムがドロップされた場合は、各パスをスペース区切りで並べる |

引数フィールドに `{drop}` を含む `app` タイルは「D&D 専用タイル」として動作し、通常クリックではアプリを起動しません。

- 通常モードでタイルをクリックしても、アプリは起動しない。
- 通常モードでタイル上にマウスオーバーすると、タイル中央に「**D&D 専用**」というテキストが表示される（通常のホバーアニメーションは行わない）。テキストの背景は角丸半径 10 px の矩形（ページ背景色・透過率 0 %）で、フォントサイズは 16 pt。
- 通常モードでファイルをタイル上へドロップすると、`{drop}` を実際のファイルパスに置換した引数でアプリを起動する。

### 3.7 右クリックメニュー

通常モード（ピンモード ON/OFF 問わず）でランチャー本体を右クリックすると表示されるコンテキストメニューです。タスクトレイアイコンを右クリックした場合も同じメニューを表示します。

```
吸着位置の指定
  ├ 上
  ├ 左
  ├ 下
  └ 右
ピンモード切替
──────────────
終了
```

| 項目 | 動作 |
|---|---|
| 吸着位置の指定 | サブメニューから選んだ方向へアニメーションなしで即時吸着し直す（瞬間移動） |
| ピンモード切替 | ピンモードの ON/OFF を切り替える |
| 終了 | アプリケーションを終了する |

**タスクトレイアイコンのクリック動作**

| 操作 | 動作 |
|---|---|
| 左クリック | 何もしない |
| 左ダブルクリック | アプリを最前面に表示してフォーカスし、ピンモードを ON にする。収納モード中の場合は、先に通常モードへの展開アニメーションを再生してからピンモードを ON にする。すでにピンモード ON の場合は、ピンモードを OFF にする |

- 収納モード中にハンドルを右クリックしても、コンテキストメニューは表示されません。
- アプリは Windows タスクバーへのアイコン表示を行いません（タスクトレイのみに表示されます）。
- タスクトレイアイコンは `resources/icons/app.ico` を使用します。同ファイルはコンパイル時に exe へも埋め込まれます。
- 収納モード中にタスクトレイアイコンから吸着方向を変更した場合は、先に通常モードへ展開してから吸着位置を変更します。
- 収納モード中にタスクトレイアイコンからピンモードを ON にした場合は、展開アニメーションを再生しながら通常モードへ移行し、完了後にピンモードを ON にします。
- タスクトレイ常駐が OFF の場合、Alt+F4 などでウィンドウを閉じようとしてもアプリは終了せずウィンドウを最小化します。アプリを終了するには右クリックメニューの「終了」を使用してください。

## 4. 共通仕様

### 4.1 透過率

アプリ内のすべての透過率設定に適用される共通ルールです。

- 設定範囲：**0 ～ 90 %**
- 入力方法：スライダーで値を変更する

### 4.2 フォントサイズ

アプリ内のすべてのフォントサイズ設定（タイルのテキスト・ページ名等）に適用される共通ルールです。

- 設定範囲：**6 ～ 72 pt**
