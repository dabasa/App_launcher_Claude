自動実行管理 — UI 仕様

  • フレーム内表示（設定モード → タイルから遷移）
  • アプリが作成したタスクのみを表示
  • タスクスケジューラーに専用フォルダ \AppLauncher\ を作成
  • タスク一覧：名前・種別バッジ・スケジュール・前回実行・結果を表示
  • 有効・無効切替、編集、削除ボタンを各行に配置

管理対象ファイル種別

  • .bat　バッチファイル
  • .py　　Python スクリプト
  • .ps1　PowerShell スクリプト
  • .exe　実行ファイル

スケジュール種別

  • 指定時間：毎日 / 毎週 / ログオン時 / PC起動時
  • 毎日・毎週は時刻（HH:MM）を指定
  • 毎週は追加で曜日を選択
  • 指定間隔：1 分単位で間隔を指定

ログ機能

  • 保存先：logs/autoexec/
  • 実行結果（終了コード）をファイルに記録
  • アプリ起動時・終了時に OS ログを読んで同期
  • アプリ内からはログを閲覧不可（ファイルのみ）

アンインストール手順

  • 管理画面フッターの「全タスクを削除」を押す
  • 確認ダイアログで OK → タスクスケジューラーの \AppLauncher\ フォルダごと削除
  • その後 exe フォルダを削除して完了

ログ仕様（確定）

  • 保持件数：50 件固定（設定変更不可）
  • 50 件超過時は古いものから削除
  • アプリ起動・終了時に OS ログを読んで同期
  • アプリ内からの閲覧不可（ファイルのみ）
