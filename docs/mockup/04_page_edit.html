ページ編集パネルの仕様

1
プレビューエリア（上部）
左: ページカラープレビュー（200×96px、角丸10px）。 ページ名が中央に表示される。背景色・不透明度の変更がリアルタイムに反映。
右: 「ページ編集」ラベル（FontSize=14, Bold）。
2
背景色 / 背景不透明度
ColorPalette の11色からプルダウン選択（カラープレビュードット付き）。
不透明度スライダー: 0〜90%（10刻み）。 デフォルト: color=gray, opacity=30（30%透明 = 70%不透明）。
フレームの背景色に適用される。
3
ハンドル色 / ハンドル不透明度
ハンドルの背景色とその不透明度。
スライダー: 0〜90%（10刻み）。 デフォルト: color=gray, opacity=20（20%透明 = 80%不透明）。
ページ毎に異なるハンドル色を設定可能。
4
ピン枠色 / ピン枠不透明度
ピン留め時のフレーム枠線の色と不透明度。
スライダー: 0〜90%（10刻み）。 デフォルト: color=white, opacity=50（50%透明 = 50%不透明）。
通常の黒枠（2px）からピン枠色の太枠（8px）に変化する。
5
ボタン色の自動計算
OK/キャンセルボタンの背景色はページ背景色を元に ColorHelper.ComputeUiElementColor() で自動計算。
HSL変換 → L ±15pt 調整（明るい色は暗く、暗い色は明るく）→ S -5pt 調整 → RGB変換。
