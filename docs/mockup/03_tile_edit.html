タイル編集パネルの仕様

1
プレビューエリア
左: タイルプレビュー（200×96px、角丸8px）。 タイトル・カラー・フォントの変更がリアルタイムに反映される。
右: 「タイル編集」ラベル。FontSize=15, SemiBold。
2
折りたたみセクション
▲/▼ でセクションを展開/折りたたみ。 ヘッダーをクリックで切替。デフォルトはすべて展開。
種類（▲ 基本 / ▲ 起動 / ▲ 見た目）。type=system の場合のみ「システム情報」セクションが表示される。
3
「起動」セクション（type≠system）
app/folder: パス・引数・作業フォルダ（参照ボタン付き）
url: URL のみ（参照ボタンなし）
settings: パスに settings://globalSettings など
引数に {drop} を含む app は D&D専用タイルとして動作。
4
「システム情報」セクション（type=system）
カテゴリ: usage/temp/clock/network
デバイス種別: cpu/gpu/memory/disk/network
表示形式: text/circle（circle は円グラフ）
基準値（%）超過時にアクセントカラーに変化。更新間隔は ms 単位。
5
「見た目」セクション
カラー: ColorPalette の11色からプルダウン選択（カラープレビュー付き）
透過率: 0〜90% スライダー（0=不透明 / 90=ほぼ透明）
フォント名: システムフォント一覧から選択
フォントサイズ: pt 単位で直接入力
フォントカラー: ColorPalette から選択
画像/アイコン: ファイルパス＋参照ボタン
表示位置: top/left/center/none
画像透過: チェックオンで画像の黒部分を透過処理
6
OK / キャンセル
OK: 変更を config に反映してタイルを再描画（フォーカス移動後に UIを更新）
キャンセル: 変更を破棄してパネルを閉じる。
ボタン色はページ背景色を元に ColorHelper.ComputeUiElementColor で自動計算（HSL ±15%）。

タイル種類別の表示差分

type 起動セクション システム情報
app 表示（参照ボタン付き） 非表示
url 表示（URL のみ） 非表示
folder 表示（参照ボタン付き） 非表示
system 非表示 表示
settings 表示（パスのみ） 非表示
