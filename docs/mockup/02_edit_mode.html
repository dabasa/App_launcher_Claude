編集モードの UI 要素

1
編集モード切替
ボトムバー右端のモードボタン（✏️）クリックで編集モードへ遷移。 ボタン背景がオレンジ色になり編集中を示す。 再クリックで通常モードに戻る。
2
タイルへのホバーオーバーレイ
編集モード中、タイルにマウスオーバーすると4つのコントロールが表示される:
✎ 編集 左上 — タイル編集パネルを開く
✕ 削除 右上 — 削除確認ダイアログを表示
⊕ コピー 左下 — タイルを複製
□ リサイズ 右下 — ドラッグでスパン変更
3
空きセル（追加ボタン）
タイルのない空きセルには「+」ボタンが表示される。 クリックでタイル編集パネルが開き、新規タイルを追加できる。 デフォルト値: type=app, color=blue, opacity=20, fontSize=16pt
4
D&D によるタイル移動
タイルをドラッグして他のセルへ移動できる。 ドラッグ中はオーバーレイに点線の矩形プレビューが表示される。 引数に {drop} を含む app タイルは 外部からのファイルドロップも受け付ける（D&D専用モード）。
5
ボトムバー（編集モード）
通常の行（32px）に加えてページ管理行（25px + 8px マージン）が表示される。
合計高さ: 32 + 8 + 25 = 65px
ページ管理行: ◀ 左移動 / ＋ 追加 / － 削除 / ▶ 右移動
右端に追加: 📝 ページ編集 / ⚙️ 全体設定 の2ボタン
6
削除確認ダイアログ
削除ボタン押下でフレーム全体に半透明オーバーレイが表示される。 中央に確認ダイアログ（幅300px × 高140px）。 gray (#8C9BAB) 背景、角丸10px。 OK: 赤 (#E05252)、キャンセル: グレー (#6D7880)。

WebView タイル（type=url）の編集オーバーレイ

WebView タイルは編集モード中に WebView を非表示にしてプレースホルダーを表示。 プレースホルダーには「WebView」ラベル、タイトル、URL が表示される。 コピーボタン（⊕）は WebView タイルには非表示（通常タイルのみ）。
