# Ph.17 実装指示書 ─ カラースタイル管理機能

対象バージョン：V1.1.0  
作成日：2026-05-24

---

## 概要

タイル編集パネルおよびページ編集パネルにカラースタイルのプリセット管理機能を追加する。  
スタイルは色・透過率のみを保持し、選択するだけで複数のカラー設定を一括適用できる。

---

## 実装内容

### 1. データモデルの追加

**対象ファイル**

- `src/AppLauncher/Models/AppConfig.cs`（またはルートモデルクラス）

**変更内容**

```csharp
public class TileStyleConfig
{
    public string Name       { get; set; } = "";
    public bool   IsDefault  { get; set; } = false;
    public string Color      { get; set; } = "#4A90D9";   // hex
    public int    Opacity    { get; set; } = 20;
    public string FontColor  { get; set; } = "#F0F0F0";   // hex
}

public class PageStyleConfig
{
    public string Name               { get; set; } = "";
    public bool   IsDefault          { get; set; } = false;
    public string BackgroundColor    { get; set; } = "#8C9BAB";
    public int    BackgroundOpacity  { get; set; } = 30;
    public string HandleColor        { get; set; } = "#8C9BAB";
    public int    HandleOpacity      { get; set; } = 20;
    public string PinFrameColor      { get; set; } = "#F0F0F0";
    public int    PinFrameOpacity    { get; set; } = 50;
}
```

`AppConfig` に以下を追加：

```csharp
public List<TileStyleConfig> TileStyles { get; set; } = new(DefaultTileStyles);
public List<PageStyleConfig> PageStyles { get; set; } = new(DefaultPageStyles);
```

デフォルトスタイルは静的フィールドとして定義する（機能定義書 §3.7 の値を参照）。

### 2. config.json のデフォルト値初期化

**対象ファイル**

- `src/AppLauncher/Services/ConfigService.cs`

**変更内容**

初回起動時（または `tileStyles` / `pageStyles` が空の場合）に、デフォルト 5 件のスタイルを自動投入する。

### 3. タイルスタイルセレクター UI

**対象ファイル**

- `src/AppLauncher/Views/Controls/TileEditPanel.xaml`
- `src/AppLauncher/ViewModels/TileEditViewModel.cs`

**XAML 構成（基本セクション最上部に追加）**

```xml
<!-- カラースタイル選択 -->
<StackPanel>
    <ComboBox ItemsSource="{Binding StyleItems}"
              SelectedItem="{Binding SelectedStyleItem}"
              DisplayMemberPath="DisplayName"/>
    <!-- 保存・削除ボタン（カスタマイズ中のみ表示） -->
    <StackPanel Orientation="Horizontal"
                Visibility="{Binding IsCustomized, Converter={...BoolToVisibilityConverter}}">
        <Button Content="保存" Command="{Binding SaveStyleCommand}"/>
        <Button Content="削除" Command="{Binding DeleteStyleCommand}"/>
    </StackPanel>
</StackPanel>
```

**ViewModel ロジック**

```csharp
// スタイル選択肢（通常スタイル ＋ 「カスタマイズ」）
public ObservableCollection<StyleItem> StyleItems { get; }

// 現在の Color/Opacity/FontColor がスタイルと一致しない場合 true
public bool IsCustomized => !StyleItems.Any(s => s.Matches(Color, Opacity, FontColor));

// スタイル選択時：Color / Opacity / FontColor を一括更新
private void ApplyStyle(TileStyleConfig style)
{
    Color     = style.Color;
    Opacity   = style.Opacity;
    FontColor = style.FontColor;
}
```

- `StyleItem.DisplayName`：通常は `style.Name`、カスタマイズ中は `"カスタマイズ"`。
- スタイルを選択すると即座に Color/Opacity/FontColor が更新され、プレビューに反映される。
- 実際のタイルへの反映は「OK」押下時。

**「保存」ボタンの動作**

1. スタイル名入力ダイアログ（`TextBox` ＋ OK ＋ キャンセル）を表示する。
2. OK 押下で新しい `TileStyleConfig`（`isDefault: false`）を `TileStyles` リストに追加する。
3. `ConfigService.SaveAsync()` を呼んで config.json に保存する。
4. プルダウンを更新し、保存したスタイルを選択状態にする。

**「削除」ボタンの動作**

1. 削除確認ダイアログを表示する（タイル削除と同じ形式）。
2. OK 押下で選択中のスタイルを `TileStyles` リストから削除する。
3. `ConfigService.SaveAsync()` を呼んで config.json に保存する。
4. `isDefault: true` のスタイルは削除コマンドを無効化する。

### 4. ページスタイルセレクター UI

**対象ファイル**

- `src/AppLauncher/Views/Controls/PageEditPanel.xaml`（または相当するページ編集パネル）
- `src/AppLauncher/ViewModels/PageEditViewModel.cs`

タイルスタイルセレクターと同じ構成・動作を実装する。  
保持する設定は `BackgroundColor` / `BackgroundOpacity` / `HandleColor` / `HandleOpacity` / `PinFrameColor` / `PinFrameOpacity`。

カスタマイズ判定は 6 項目すべてが一致する場合のみ「スタイル適用中」とする。

### 5. 色値の表現統一（Ph.16 との連携）

Ph.16 で `ColorPalette.GetColor()` が hex 値を直接パースできるよう拡張済みであること前提。  
スタイルの色はすべて hex 値（`#RRGGBB`）で保持するため、`ColorPalette.GetColor()` がそのまま使用できる。
