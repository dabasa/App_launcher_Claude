# Ph.21 実装指示書 ─ リリース付属 HTML 操作ガイド

対象バージョン：V1.2.0  
作成日：2026-05-31

---

## 概要

アプリリリース時に同梱する操作方法ガイドを HTML 形式で作成する。  
ユーザーがアプリを初めて起動した後に参照できる、わかりやすいリファレンスドキュメントとする。

---

## 成果物

| ファイル | 配置場所 | 内容 |
|---|---|---|
| `manual.html` | アプリ実行ファイルと同じフォルダ | メインガイド（全機能） |
| `assets/` | `manual.html` と同階層 | 画像・スタイルシート等 |

> アプリの「ヘルプ」ボタン（未実装）から `manual.html` を規定ブラウザで開く動線も検討する。

---

詳細は別途詰める。以下は骨格案。

## デザイン要件

> **詳細は後ほど詰める。** 以下は方針のみ記載。

- アプリの UI カラーに合わせたダークテーマベースのデザイン
- 単一 HTML ファイルで完結（外部 CDN に依存しない）
- スクリーンショットを適宜挿入して視覚的にわかりやすくする
- モバイル表示は考慮しない（PC 専用アプリのため）
- 日本語のみ対応

---

## 技術要件

| 項目 | 要件 |
|---|---|
| 外部依存 | なし（CDN 不使用。CSS・JS はインライン or 相対パス） |
| 文字コード | UTF-8 |
| 対象ブラウザ | Microsoft Edge（規定ブラウザとして想定） |
| 画像フォーマット | PNG または WEBP |
| スタイル管理 | `<style>` タグ内に記述（外部 CSS ファイルは可） |

## 実装手順（TBD 部分を除く骨格）

### 1. HTML テンプレート作成

基本レイアウト（ヘッダー・サイドメニュー・コンテンツエリア）を HTML/CSS で作成する。

### 2. スクリーンショット撮影

各機能のスクリーンショットを撮影し `assets/img/` フォルダに保存する。

### 3. 各セクションのコンテンツ執筆

セクションごとにテキストと画像を組み合わせて記述する。

### 4. リンク動線の確認

`manual.html` をブラウザで開いて、内部リンク・画像パスが正しいか確認する。

### 5. アプリへの組み込み（オプション）

グローバル設定画面またはタスクトレイメニューに「ヘルプを開く」を追加し、  
`Process.Start(new ProcessStartInfo("manual.html") { UseShellExecute = true })` で開く。

## テスト観点

| # | 確認内容 | 期待結果 |
|---|---|---|
| 1 | `manual.html` をブラウザで開く | レイアウトが崩れず表示される |
| 2 | 内部リンク（目次 → 各セクション）を確認 | 正しくスクロールまたは遷移する |
| 3 | 全画像が表示される | 画像が欠けない（パス正常） |

| 5 | アプリ本体からヘルプを開く（実装した場合） | 既定ブラウザで `manual.html` が開く |
