# Ph.13 実装指示書 ─ フォントサイズのスライダー操作＋自動調整

対象バージョン：V1.1.0  
作成日：2026-05-24

---

## 概要

タイル編集画面のフォントサイズ設定を、スライダー操作で変更できるようにする。  
あわせて「フォントサイズの自動調整」チェックボックスを追加する。

---

## 実装内容

### 1. フォントサイズスライダーの追加

**対象ファイル**

- `src/AppLauncher/Views/Controls/TileEditPanel.xaml`（見た目セクション）
- `src/AppLauncher/ViewModels/TileEditViewModel.cs`

**変更内容**

現在のフォントサイズ入力フィールドをスライダーに変更する（または数値表示と連動させる）。

```xml
<!-- XAML イメージ -->
<Slider Minimum="6" Maximum="72" Value="{Binding FontSizePt}"
        IsEnabled="{Binding AutoFontSize, Converter={...InvertBoolConverter}}"
        TickFrequency="1" IsSnapToTickEnabled="True"/>
<TextBlock Text="{Binding FontSizePt, StringFormat={}{0} pt}"
           HorizontalAlignment="Center"/>
```

- スライダーの範囲は 6 〜 72 pt（既存の仕様と同じ）。
- スライダーの横に現在値を `XX pt` 形式で表示する。
- `AutoFontSize` が `true` の場合、スライダーをグレーアウト（`IsEnabled="False"`）にする。

### 2. フォントサイズ自動調整チェックボックスの追加

**対象ファイル（同上）**

```xml
<!-- XAML イメージ -->
<CheckBox Content="フォントサイズを自動調整する"
          IsChecked="{Binding AutoFontSize}"/>
```

チェックボックスはフォントサイズスライダーの直下に配置する。

### 3. `autoFontSize` の ViewModel ＆ Model 対応

**対象ファイル**

- `src/AppLauncher/ViewModels/TileEditViewModel.cs`
- `src/AppLauncher/Models/TileModel.cs`（または相当するモデルクラス）
- `src/AppLauncher/Services/ConfigService.cs`（JSON シリアライズ対応）

**変更内容**

- `TileModel` に `bool AutoFontSize` プロパティを追加する。
- `TileEditViewModel` に `AutoFontSize` プロパティを追加し、変更時に `FontSizePt` スライダーの有効/無効を切り替える。
- `config.json` の `autoFontSize` キー（boolean）として保存・読み込みを行う。

### 4. 自動調整ロジックの実装

**対象ファイル**

- `src/AppLauncher/Views/Controls/TileControl.xaml.cs`（または描画を担当するコントロール）

**変更内容**

`AutoFontSize` が `true` の場合、タイルの描画領域に文字列が収まる最大フォントサイズを自動計算する。

```csharp
private double CalcAutoFontSize(string text, double availableWidth, double availableHeight)
{
    for (double size = 72; size >= 6; size--)
    {
        var formattedText = new FormattedText(
            text,
            CultureInfo.CurrentCulture,
            FlowDirection.LeftToRight,
            new Typeface(FontFamily),
            size,
            Brushes.Black,
            VisualTreeHelper.GetDpi(this).PixelsPerDip);

        if (formattedText.Width <= availableWidth && formattedText.Height <= availableHeight)
            return size;
    }
    return 6;
}
```

- 自動計算のトリガー：タイルのレイアウト更新時（`SizeChanged` イベント等）および表示テキストの変更時。
- 計算結果は UI 表示のみに使用し、`TileModel.FontSizePt` には書き込まない（config.json の値は変えない）。

### 5. デフォルト値

- `autoFontSize` の初期値は `false`。
- 新規タイル作成時のデフォルトは `false`（既存の動作を維持）。

## テスト観点

| # | 確認内容 | 期待結果 |
|---|---|---|
| 1 | スライダーを動かす | フォントサイズが 6〜72 の範囲で変化する |
| 2 | 自動調整チェックを ON にする | スライダーがグレーアウトし、操作できなくなる |
| 3 | 自動調整 ON でタイルを表示する | テキストがタイル領域に収まる最大サイズで表示される |
| 4 | タイルサイズを変更する（自動調整 ON） | フォントサイズが再計算される |
| 5 | 自動調整チェックを OFF にする | スライダーが再び操作可能になり、元の `fontSizePt` 値で表示される |
| 6 | config.json に `autoFontSize: true` を保存し再起動する | 自動調整 ON の状態で復元される |
