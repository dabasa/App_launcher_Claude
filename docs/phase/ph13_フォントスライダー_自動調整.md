# Ph.13 実装指示書 ─ フォントサイズのスライダー操作＋自動調整

対象バージョン：V1.1.0  
作成日：2026-05-24  
実装完了：2026-05-30

---

## 概要

タイル編集画面のフォントサイズ設定を、スライダー操作で変更できるようにする。  
あわせて「フォントサイズの自動調整」チェックボックスを追加する。

---

## 実装内容

### 1. フォントサイズスライダーの追加

**実装ファイル**

- `src/AppLauncher/Views/Controls/FontDetailPanel.xaml`
- `src/AppLauncher/ViewModels/FontDetailViewModel.cs`

スライダー（6〜72pt）と現在値表示を `FontDetailPanel` 内に実装。  
`AutoFontSize = true` の場合、スライダーをグレーアウト（Opacity=0.4）。

### 2. フォントサイズ自動調整チェックボックスの追加

`FontDetailPanel` 内にチェックボックスとして実装。

```xml
<CheckBox Content="フォントサイズを自動調整する（はみ出す場合のみ縮小）"
          IsChecked="{Binding AutoFontSize, UpdateSourceTrigger=PropertyChanged}"/>
```

### 3. `autoFontSize` の ViewModel・Model 対応

- `FontConfig` に `bool AutoFontSize { get; set; } = false` を追加
- `FontDetailViewModel` に `AutoFontSize` プロパティを追加
- `TileEditViewModel` の `TitleFont` / `ContentFont` ワークコピーを通して伝達
- `config.json` の `titleFont.autoFontSize` として保存・読み込み

### 4. 自動調整ロジックの実装

**実装ファイル**

- `src/AppLauncher/Views/Controls/TileControl.xaml.cs`

`AutoFontSize = true` の場合、指定 `FontSizePt` を上限として、タイル領域に収まる最大フォントサイズを自動計算する。  
`FormattedText` は WPF の実描画より行高が小さく出るため、`TextBlock.Measure()` を使用する。

```csharp
private double CalcOverflowFontSize(string text, double w, double h)
{
    if (string.IsNullOrEmpty(text) || w <= 0 || h <= 0) return 6;

    var measure = new TextBlock
    {
        Text         = text,
        TextWrapping = TextWrapping.Wrap,
        FontFamily   = TitleText.FontFamily,
        FontStyle    = TitleText.FontStyle,
        FontWeight   = TitleText.FontWeight,
        FontStretch  = TitleText.FontStretch,
        Padding      = new Thickness(8),
    };
    double availW = w + 16;
    double availH = h + 16;

    double startPt = Math.Clamp(_tile.FontSizePt, 6, 72);
    for (double size = startPt; size >= 6; size--)
    {
        measure.FontSize = size * 4.0 / 3.0;
        measure.Measure(new Size(availW, double.PositiveInfinity));
        if (measure.DesiredSize.Height <= availH) return size;
    }
    return 6;
}
```

- 自動計算のトリガー：`OnLoaded`（初回レイアウト後）および `SizeChanged`
- `OnLoaded` 時点で `ActualWidth = 0` の場合は `Dispatcher.BeginInvoke` で遅延実行
- 計算結果は UI 表示のみに使用し、`config.json` の値は変更しない

### 5. デフォルト値

- `autoFontSize` の初期値は `false`
- 新規タイル作成時のデフォルトは `false`（既存動作を維持）

## 実装時の修正事項

### FormattedText → TextBlock.Measure への変更

当初は `FormattedText` を使用する設計だったが、  
`FormattedText.Height` は WPF TextBlock の実描画より行高が小さく計算される（`FontFamily.LineSpacing` 分の誤差）。  
この誤差によりテキストがはみ出す問題が発生したため、`TextBlock.Measure()` を使用する実装に変更した。

### SystemTileControl の対応

`SystemTileControl` のタイトルフォントおよびコンテンツフォントについても、  
Ph.F-D の実装と合わせて AutoFontSize 対応を行った（詳細は `phFD_AutoFont最適サイズ.md` を参照）。
