# Ph.15 実装指示書 ─ system タイル 縦棒グラフ表示形式追加

対象バージョン：V1.1.0  
作成日：2026-05-24

---

## 概要

システムタイルの表示形式に「縦棒グラフ」（`"bar"`）を追加する。  
対象は情報カテゴリ「使用率」のうち CPU・メモリ・GPU のみ（LAN は対象外）。

---

## 実装内容

### 1. displayFormat 定数の追加

**対象ファイル**

- `src/AppLauncher/Models/SystemInfo/DisplayFormat.cs`（または相当する列挙体）

**変更内容**

```csharp
public enum DisplayFormat
{
    Text,
    Circle,
    Bar,   // 追加
}
```

### 2. 縦棒グラフ描画の実装

**対象ファイル**

- `src/AppLauncher/Views/Controls/SystemTileControl.xaml.cs`（または system タイルの描画を担当するコントロール）

**描画仕様**

- タイル内に縦棒グラフを描画する。
- グラフは使用率（0〜100%）を縦棒の高さで表現する。
- メインカラー：使用率部分（棒の塗りつぶし色）。
- アクセントカラー：使用率が基準値を超えた場合の棒の塗りつぶし色。
- 背景アクセント：使用率が基準値を超えた場合のタイル背景色（円形グラフと同じ動作）。
- 基準値：アクセント・背景アクセントが適用されるしきい値（%）。

**描画イメージ**

```
 ┌──┐         ← 使用率 100% ライン
 │  │
 │██│         ← 現在の使用率（例：65%）
 │██│
 │██│
 └──┘
  CPU
```

- 棒の下部にデバイス名（`CPU` / `MEM` / `GPU`）を表示する。
- 使用率のパーセント値をグラフ上部またはグラフ内に数値テキストで表示する。
- グラフ外枠は薄いグレーの矩形で描画する。

**実装方針**

WPF の `DrawingContext` または `Canvas` + `Rectangle` で描画する。  
既存の円形グラフ（`DisplayFormat.Circle`）の描画コードを参考に、縦棒グラフ用のロジックを追加する。

```csharp
private void DrawBarGraph(DrawingContext dc, double usagePercent)
{
    var layout = App.ConfigService.Current.Layout;
    double width  = ActualWidth;
    double height = ActualHeight;

    bool isOverThreshold = usagePercent >= Threshold;
    var fillBrush = isOverThreshold
        ? new SolidColorBrush(ColorPalette.GetColor(AccentColor))
        : new SolidColorBrush(ColorPalette.GetColor(MainColor));

    double barHeight = height * (usagePercent / 100.0);
    double barTop    = height - barHeight;

    // 棒グラフ描画
    dc.DrawRectangle(fillBrush, null, new Rect(/* x, barTop, width, barHeight */));

    // 数値テキスト描画
    var text = new FormattedText($"{usagePercent:F0}%", ...);
    dc.DrawText(text, new Point(/* center */));
}
```

### 3. タイル編集 UI の対応

**対象ファイル**

- `src/AppLauncher/Views/Controls/TileEditPanel.xaml`
- `src/AppLauncher/ViewModels/TileEditViewModel.cs`

**変更内容**

表示形式のプルダウンに「縦棒グラフ」を追加する。  
以下の条件でのみ「縦棒グラフ」を選択可能にする：

- カテゴリ = `usage`
- デバイス種別 = `cpu` / `memory` / `gpu`

LAN・OS情報・ストレージ・TOPプロセスカテゴリでは「縦棒グラフ」を選択不可（プルダウンで非表示または無効化）にする。

### 4. config.json 対応

- `systemInfo.displayFormat` の値として `"bar"` を保存・読み込みできること。
