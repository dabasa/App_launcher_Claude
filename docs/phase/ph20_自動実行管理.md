# Ph.20 実装指示書 ─ 自動実行管理ツール

対象バージョン：V1.1.0  
作成日：2026-05-24

---

## 概要

Windows タスクスケジューラーと連携した自動実行タスクの管理機能をアプリ内に実装する。  
アプリが作成したタスクのみを管理し、OS 全体のタスクには干渉しない。

**UI モックアップ**：`docs/mockup/06_auto_exec.html` 参照

---

## 仕様まとめ

| 項目 | 内容 |
|---|---|
| スケジューラー | Windows タスクスケジューラー（現在ユーザー権限・管理者不要） |
| 管理対象拡張子 | `.exe` / `.bat` / `.ps1` / `.py` |
| タスク格納先 | タスクスケジューラーの `\AppLauncher\` フォルダ |
| 管理範囲 | アプリが作成したタスクのみ（`\AppLauncher\` 配下のみ） |
| 画面位置 | フレーム内（設定モード → 「自動実行管理」タイルから遷移） |
| ログ保持件数 | 50 件固定（設定変更不要） |
| アンインストール手段 | 管理画面フッターの「全タスクを削除」ボタン |

## 実装内容

### 1. タスクスケジューラー連携サービスの作成

**対象ファイル（新規）**

- `src/AppLauncher/Services/TaskSchedulerService.cs`

**使用ライブラリ**

`Microsoft.Win32.TaskScheduler`（NuGet パッケージ `TaskScheduler`）を使用する。  
管理者権限不要でタスクの作成・読取・有効化・無効化・削除が可能。

**実装すべきメソッド**

```csharp
public class TaskSchedulerService
{
    private const string FolderPath = "\\AppLauncher\\";

    // タスク一覧取得（AppLauncher フォルダのタスクのみ）
    public IReadOnlyList<AutoExecTaskInfo> GetTasks();

    // タスク作成
    public void CreateTask(AutoExecTaskConfig config);

    // タスク更新（既存タスクを上書き）
    public void UpdateTask(string taskName, AutoExecTaskConfig config);

    // タスク削除（1件）
    public void DeleteTask(string taskName);

    // 全タスク削除（アンインストール用）
    public void DeleteAllTasks();

    // 有効・無効切替
    public void SetEnabled(string taskName, bool enabled);

    // 前回実行時刻・実行結果の取得
    public (DateTime? LastRunTime, int? ExitCode) GetLastRunInfo(string taskName);
}
```

**`AutoExecTaskInfo`（表示用モデル）**

```csharp
public record AutoExecTaskInfo(
    string   Name,
    string   FilePath,
    string   Args,
    string   ScheduleDescription,  // 表示用文字列（例："毎日 12:00"）
    bool     IsEnabled,
    DateTime? LastRunTime,
    int?     LastExitCode
);
```

**`AutoExecTaskConfig`（作成・編集用モデル）**

```csharp
public class AutoExecTaskConfig
{
    public string       Name       { get; set; } = "";
    public string       FilePath   { get; set; } = "";
    public string       Args       { get; set; } = "";
    public ScheduleType Type       { get; set; } = ScheduleType.Daily;
    public TimeSpan     Time       { get; set; } = new(12, 0, 0);
    public DayOfWeek[]  DaysOfWeek { get; set; } = [];  // 毎週のみ使用
    public int          IntervalMinutes { get; set; } = 60;  // 指定間隔のみ使用
}

public enum ScheduleType { Daily, Weekly, AtLogon, AtStartup, Interval }
```

### 2. ログ機能の実装

**対象ファイル（新規）**

- `src/AppLauncher/Services/AutoExecLogService.cs`

**ログ保存先**

```
<exe フォルダ>/logs/autoexec/<タスク名>.log
```

**ログフォーマット（1エントリー1行、CSV 形式）**

```
2026-05-24T12:05:00,成功,0
2026-05-24T11:00:00,失敗,1
```

各フィールド：`実行日時（ISO 8601）` / `結果（成功/失敗）` / `終了コード`

**実装仕様**

```csharp
public class AutoExecLogService
{
    private const int MaxEntries = 50;  // 固定

    // アプリ起動・終了時に OS のタスクスケジューラーログを読んでローカル .log に追記する
    public void SyncFromTaskScheduler(string taskName, DateTime sinceUtc);

    // ログファイルを読んで最新 N 件を返す（UI 表示用）
    public IReadOnlyList<AutoExecLogEntry> ReadLog(string taskName);

    // 内部：50件超過分を削除
    private void TrimLog(string logPath);
}

public record AutoExecLogEntry(DateTime RunAt, bool Success, int ExitCode);
```

**ログ同期タイミング**

- アプリ起動時：全タスクについてローカルログを更新する
- アプリ終了時：再度同期して最新情報を反映する
- `sinceUtc` は前回同期時刻（最後のログエントリーの日時）を渡す

### 4. View の作成（フレーム内パネル）

**対象ファイル（新規）**

- `src/AppLauncher/Views/Controls/AutoExecPanel.xaml`
- `src/AppLauncher/Views/Controls/AutoExecPanel.xaml.cs`

レイアウトは `docs/mockup/06_auto_exec.html` に準拠する。

- ヘッダー：「自動実行管理」
- タスク一覧（`ScrollViewer` + `ItemsControl`）
  - 各行：タスク名・種別バッジ・スケジュール・前回実行・結果・有効/無効ボタン・編集・削除
- フッター：「全タスクを削除」（左寄せ）・「閉じる」（右寄せ）

**タスク追加・編集ダイアログ**

- 既存の確認ダイアログと同じ形式（フレーム内オーバーレイ）
- 入力項目：タスク名・実行ファイルパス（参照ボタン付き）・引数・スケジュール設定

**スケジュール設定 UI**

| 状態 | 表示内容 |
|---|---|
| 指定時間 > 毎日 | 時刻（HH:MM） |
| 指定時間 > 毎週 | 時刻（HH:MM）＋ 曜日チェック（月〜日） |
| 指定時間 > ログオン時 | なし |
| 指定時間 > PC起動時 | なし |
| 指定間隔 | 間隔（分） |

### 5. アプリ全体への統合

**設定モードのタイル一覧に追加**

- `src/AppLauncher/ViewModels/LauncherViewModel.cs`（設定タイル一覧の定義箇所）
- 全体設定タイルの隣に「自動実行管理」タイルを追加する。

**アプリ起動・終了時のログ同期**

- `src/AppLauncher/App.xaml.cs`（`OnStartup` / `OnExit`）
- `AutoExecLogService.SyncFromTaskScheduler()` を全タスク分呼び出す。

**「全タスクを削除」の確認ダイアログ**

既存のタイル削除ダイアログと同じ形式を流用する。  
メッセージ：「登録されている全タスクをタスクスケジューラーから削除します。よろしいですか？」

### 6. タスクスケジューラーフォルダの管理

- タスク作成時、`\AppLauncher\` フォルダが存在しなければ自動作成する。
- 「全タスクを削除」実行時、タスクを全件削除した後に `\AppLauncher\` フォルダ自体も削除する。

## テスト観点

| # | 確認内容 | 期待結果 |
|---|---|---|
| 1 | 設定モードの「自動実行管理」タイルをクリック | 管理画面に遷移する |
| 2 | タスクを追加する | タスクスケジューラーの `\AppLauncher\` フォルダにタスクが登録される |
| 3 | 有効・無効ボタンを押す | タスクスケジューラー側の有効/無効状態が変わる |
| 4 | スケジュール通りに実行される | 指定したファイルが実行され、ログに記録される |
| 5 | ログが 50 件を超える | 古いエントリーが削除され 50 件に収まる |
| 6 | アプリ起動時 | OS ログが読み込まれ前回実行時刻・結果が更新される |
| 7 | 「全タスクを削除」→ 確認 OK | 全タスクが削除され `\AppLauncher\` フォルダも消える |
| 8 | 「全タスクを削除」→ 確認キャンセル | タスクは削除されない |
| 9 | 管理者権限なしで全操作が行えること | UAC プロンプトが表示されない |
| 10 | `.py` ファイルを登録する | Python インタープリター経由で実行される |

> **`.py` の実行について**：`python.exe` が環境変数 PATH に含まれていない場合は実行時エラーになります。これはユーザー環境の責任とし、アプリ側での PATH 解決・エラーハンドリングは実装しません。
